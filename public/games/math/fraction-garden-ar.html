Fraction Garden

AR Motion Arena • เกมเปรียบเทียบเศษส่วนหรรษา

✨ วิธีการเล่นด้วยร่างกาย (AR Motion):

1. ยืนให้ตัวอยู่ตรงกลางกล้องเว็บแคม

2. สังเกตโจทย์เศษส่วนซ้าย-ขวาที่จะปรากฏขึ้น

3. **เดิน/เอนตัว** ไปยังเลนสัญลักษณ์เปรียบเทียบที่ถูกต้อง:

• **เลนซ้าย** = น้อยกว่า ( < )

• **เลนกลาง** = เท่ากับ ( = )

• **เลนขวา** = มากกว่า ( > )

4. ยืนค้างไว้จนแถบพลังสีเต็ม (1.2 วินาที) หรือรอหมดเวลาเพื่อตอบ!

📷 ไม่มีกล้อง? สามารถแตะ/คลิกเลือกเลนเพื่อตอบได้เช่นกัน
