# Prompt: สร้างสื่อการสอน HTML สำหรับระบบ kampai-school

> คัดลอกข้อความทั้งหมดด้านล่างนี้ไปวางให้ AI (ChatGPT / Gemini / Claude / ฯลฯ)
> แล้วบอกไอเดียสื่อที่อยากได้ต่อท้าย. ผลลัพธ์คือ **สื่อสาธิต** ไม่ใช่เกมแข่งคะแนน.
>
> ในหลังบ้าน: GamesTab → การ์ด **"📚 สร้างสื่อการสอนด้วย AI"** → ดาวน์โหลดเทมเพลต / คัดลอก Prompt

---

คุณคือผู้เชี่ยวชาญสร้าง **สื่อการสอนแบบ interactive** เป็น **single-file HTML** (HTML+CSS+JS ในไฟล์เดียว)
สำหรับชั้นประถมไทย สร้างตามไอเดียที่ฉันจะบอก โดย **ต้องทำตามข้อกำหนดนี้อย่างเคร่งครัด**:

> นี่คือ **สื่อ (media)** ไม่ใช่เกม (games)
> - ไม่มีคะแนนสะสม / leaderboard / lives / timer แข่ง
> - ใช้สาธิตบนโปรเจคเตอร์หรือแท็บเล็ตในห้องเรียน
> - มีปุ่ม **แสดงเฉลย / สุ่มตัวอย่าง / กลับคลังสื่อ**

## โครงไฟล์
- เป็นไฟล์ `.html` ไฟล์เดียว รันได้ในเบราว์เซอร์ทันที
- ใช้ DOM หรือ SVG/canvas ก็ได้ · ใช้ CDN ได้ · **ห้ามใช้ Firebase / backend อื่น**
- ใส่บรรทัดนี้ใน `<head>` หรือต้น `<body>`:
  ```html
  <script src="/games/kampai-sdk.js"></script>
  ```
- เรียก `KAMPAI.setSlug('my-media-slug')` ครั้งเดียวตอนเริ่ม (optional แต่แนะนำ)
- **ห้ามบังคับ** `submitScore` / ตารางอันดับ / การ์ดสถิติฉัน / D-pad
- ปุ่มกลับใช้ลิงก์: `<a href="/h/nattapong">← กลับคลังสื่อ</a>`
  (หรือ `KAMPAI.goHome()` ถ้ามี SDK)

## โครงสร้างหน้าจอมาตรฐาน (สื่อ)

1. **Header** — ปุ่มกลับคลังสื่อ + ชื่อสื่อภาษาไทยชัด + ป้ายชั้น/วิชา (เช่น `ป.3–5 · คณิตศาสตร์`)
2. **Sidebar (ซ้ายหรือบนมือถือ)** — ตัวควบคุม: เลือกโหมด / กรอกค่า / สุ่ม / แสดงเฉลย / ซ่อนเฉลย / เต็มจอ
3. **พื้นที่หลัก** — แสดงโมเดล/แผนภาพ/ตัวเลขขนาดใหญ่ อ่านจากระยะโปรเจคเตอร์ได้
4. **กล่องเฉลย** — ซ่อนไว้ก่อน กดปุ่มถึงโชว์ (คำตอบ + คำอธิบายสั้น ๆ ภาษาไทย)
5. **Footer** — `🏫 โรงเรียนบ้านคำไผ่ · สื่อการสอน`

อ้างอิงเลย์เอาต์: `public/games/_template-media.html` และตัวอย่างจริง
`public/games/math/rounding.html`, `public/games/math/fraction-pieces.html`

## สไตล์ UI (บังคับโทนสื่อ — ไม่ใช่เกมอาร์เคด)
- ฟอนต์ **Sarabun** (Google Fonts)
- พื้นหลังสว่าง (ครีม / ฟ้าอ่อน / ส้มอ่อน) — **ห้ามพื้นหลังมืดแบบเกม**
- ปุ่มใหญ่กดง่าย (≥44px) · ตัวอักษรหลักใหญ่พอโปรเจคเตอร์
- สีหลัก: navy `#1e3a8a` + accent ตามวิชา (คณิต=ฟ้า/ส้ม, ไทย=แดงทอง, วิทย์=เขียว, อังกฤษ=ฟ้ามิ้นต์)
- Responsive: มือถือเรียงแนวตั้ง, เดสก์ท็อป sidebar ซ้าย + เนื้อหาขวา
- **ไม่มี** HUD คะแนน / หัวใจ / ตารางอันดับ

## ปฏิสัมพันธ์ที่แนะนำ
- แตะ / คลิก / ลาก (ถ้าเหมาะ) — ไม่บังคับกล้อง
- ปุ่ม **สุ่ม** ตัวอย่างใหม่
- ปุ่ม **แสดงเฉลย** + **ซ่อนเฉลย**
- เปลี่ยนค่าแล้วต้อง **ซ่อนเฉลยอัตโนมัติ** (กันเด็กเห็นคำตอบเก่า)
- Optional: TTS ด้วย `KAMPAI.sound.speak(text, 'th-TH')` เมื่อมี SDK

## เมื่อส่งมอบ — บอกฉันด้วย
1. ชื่อไฟล์แนะนำ: `public/games/{subject}/{slug}.html`
   - subject เช่น `math` / `thai` / `english` / `science`
2. `title` ภาษาไทยสำหรับคลังสื่อ
3. `description` สั้น ๆ
4. `grade_levels` เช่น `ป.3,ป.4,ป.5`
5. `subject` ภาษาไทย เช่น `คณิตศาสตร์`
6. tags ที่เกี่ยวข้อง

ระบบจะ seed เป็นหมวด **คลังสื่อการสอน** (`category_key = 'media'`, `tracked_game = false`, `item_type = 'link'`)

## ห้าม
- ❌ คะแนน / lives / timer แข่ง / leaderboard / จอเกมโอเวอร์
- ❌ ช่องกรอกชื่อผู้เล่น / login / Firebase
- ❌ พื้นหลังมืด โทนอาร์เคด / พิกเซลเรโทรแบบเกม
- ❌ บังคับกล้องหรือเซ็นเซอร์ (ยกเว้นฉันขอสื่อ AR โดยเฉพาะ และต้องมี tap fallback)
- ❌ ความกว้างคงที่ที่ทำให้มือถือเลื่อนแนวนอน
- ❌ ตั้งชื่อตัวแปรทับ JS global (`Map`, `Image`, `Text`, `History`, …)
