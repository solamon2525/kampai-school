> **วิธีหลัก (แนะนำ): ปุ่ม "ปก AI" ในหลังบ้าน** — ไม่ต้องพิมพ์ prompt เอง

## วิธีหลัก — เช็กลิสต์ในหลังบ้าน (ไม่ต้องพิมพ์)

หลังบ้าน → คลังเกม (GamesTab) → การ์ดเกม → ปุ่ม **"ปก AI"**:

1. คลิก **"ชุดสำเร็จรูป"** 1 อัน (🧸 น่ารัก / ⚔️ แอ็กชัน / ✨ 3D มันวาว / 🏆 โปสเตอร์ / 📖 นิทาน) หรือกด **🎲 สุ่ม** — เซ็ตทุกแกนให้เลย
2. ปรับเพิ่มทีละชิปได้: **สไตล์ภาพ · โทนสี · ตัวเอก · ฉาก/กิจกรรม · ฉากหลัง · เอฟเฟกต์**
3. เลือก **สไตล์โลโก้ชื่อเกม**: คลาสสิก / ทองนูน / แบนเนอร์ / ป๊อป / นีออน — เปลี่ยนได้ทันทีโดยไม่ต้องสร้างภาพใหม่
4. กด **"สร้างภาพ"** → ดูตัวอย่าง → **"ใช้ปกนี้"**

ด้วยฟอนต์ Sarabun → ไทยคมชัด ไม่เพี้ยน). เพิ่ม/แก้สไตล์ที่ `src/components/admin/educational-hub/coverPresets.ts` ที่เดียว.

## วิธีสำรอง — คัดลอก prompt ไปใช้ AI ภายนอก

> คัดลอกข้อความด้านล่างไปวางใน **Canva AI** (หรือ AI สร้างภาพอื่น เช่น ChatGPT / Gemini / Claude)
> แล้ว **เติมช่องในวงเล็บปีกกา `{...}`** ให้ตรงกับเกมของคุณ → ได้ปกสไตล์เดียวกับเกมอื่นในระบบ
> ขนาดที่ต้องการ: **16:9 (1280×720)** — ใน Canva เลือกประเภท "YouTube Thumbnail"

---

สร้าง **ปกเกมการศึกษาสำหรับนักเรียนประถม** ขนาด **16:9 (1280×720 px)**
สไตล์ **การ์ตูน chibi น่ารัก ลายเส้นสะอาดตา flat design สีสันสดใส** เหมาะกับเด็กประถม

**มาตรฐานที่ต้องมีครบ:**
1. **สดใสระดับประถม** — โทนสีสดใสร่าเริง พื้นหลังไล่เฉดสว่าง มีประกายดาว/ไอคอนธีมของวิชา
2. **มีเด็กนักเรียนเป็นตัวเอก** — เด็ก chibi ตัวเล็กหัวโตน่ารัก **ใส่ชุดนักเรียนไทย**
   (เสื้อเชิ้ตขาว กางเกง/กระโปรงสีกรมท่า) ยิ้มแย้มสดใส
3. **ภาพประกอบ + ฉากเด่น** — เด็กกำลัง **{ตัวละคร/ฉาก/อุปกรณ์เด่น ที่สื่อ gameplay เช่น
   "ต่อวงจรไฟฟ้าเข้าหลอดไฟที่สว่างขึ้น" / "ระบายผีเสื้อสมมาตรบนขาตั้งภาพ"}** ให้ฉากเด่นชัดเป็นจุดสนใจกลางภาพ
4. **ปกตรงกับเกม สื่อความหมายจากรูปได้** — มองรูปแล้วเดาได้ทันทีว่าเกมเกี่ยวกับอะไร
   ไม่ใช่ภาพสวยลอย ๆ ที่ไม่เกี่ยวกับเนื้อเกม

**ตัวหนังสือบนปก:**
- หัวเรื่องตัวใหญ่ภาษาไทย: **"{ชื่อเกม}"** — เด่นชัด อ่านง่าย ไม่ถูกภาพบัง
- ป้ายเล็ก: **"{วิชา} {ระดับชั้น เช่น ป.4-6}"**

**โทนสีหลัก:** {โทนสี เช่น ฟ้า-น้ำเงิน (วิทยาศาสตร์) / ม่วง-ทอง (ศิลปะ) / เขียว (การงาน) — เลือกให้เข้ากับวิชา}

**ข้อควรระวัง (สำคัญ):**
- ⚠️ **ตรวจตัวหนังสือภาษาไทยให้ถูกต้องทุกตัว** — AI มักสะกดเพี้ยน/หล่นคำ ให้ตรวจซ้ำหลังสร้าง
- อย่าใส่ภาพรกจนชื่อเกมอ่านไม่ออก — เว้นที่ว่างให้หัวเรื่องชัด
- ส่งออกเป็น **PNG** ความละเอียดสูง (1280×720)

**ชื่อเกม + ฉากของฉันคือ:** _(พิมพ์ต่อท้ายตรงนี้ — เช่น "เกม 'นับเงินทอน' วิชาการงาน ป.4-6 เด็กเป็นแคชเชียร์ร้านค้า")_
