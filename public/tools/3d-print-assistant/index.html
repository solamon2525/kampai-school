        💡 วิธีนำเข้า: ใน Bambu Studio หรือ OrcaSlicer ไปที่เมนู File → Import → Import Configs… แล้วเลือกไฟล์ .json ค่าทั้งหมดจะเข้าไปอยู่ในแถบ Process (User Presets) ทันที

        ประเภทรูปที่ต้องการวิเคราะห์
        ข้อความหรือคำถามที่ต้องการถามเพิ่มเติม

        💡 คำแนะนำการวิเคราะห์ภาพด้วย AI

        เมื่ออัปโหลดรูปภาพชิ้นงานจริงหรือหน้าจอสไลเซอร์ ระบบจะประกอบข้อมูลทางเทคนิคของเครื่องพิมพ์ หัวพิมพ์ เส้นพลาสติก และประเภทงาน เพื่อสร้างข้อความ Prompt นำไปสอบถาม AI (เช่น Claude หรือ ChatGPT) เพื่อวิเคราะห์หาสาเหตุและวิธีแก้ไขได้อย่างแม่นยำ

        ข้อความ Prompt ที่พร้อมนำไปใช้:

        ผู้ช่วยตั้งค่าพิมพ์โมเดล 3D · พัฒนาสำหรับห้องปฏิบัติการและนักเรียน Kampai School · ค่าพารามิเตอร์อิงมาตรฐาน Bambu Studio, OrcaSlicer, Anycubic Slicer Next และ Creality Print
