นับถอยหลังทุกวินาที

กำลังจบด่าน = 0 (ยังไม่เคลียร์)
Subtract 1 from เวลา
time_text → Set text
4

หมดเวลา → Game Over

เวลา ≤ 0 + Trigger once + กำลังจบด่าน=0
โชว์ layer popup · ซ่อน/ล็อกผู้เล่น · บันทึกอันดับ = 1

เคลียร์ด่านสำเร็จ: คะแนน += เวลาที่เหลือ (บท 13)

5

ขั้นตอนสร้าง Event หมดเวลา

  1. Add condition: System → Compare variable → เวลา ≤ 0
  2. Add: Trigger once while true
  3. Actions: Set layer popup visible · Set บันทึกอันดับ = 1
