ตกฉาก / โดนดาเมจ / Flash

Is outside layout · ชน eminy · Flash อมตะ 3 วินาที

เป้าหมายบทนี้: เมื่อตกฉากหรือโดนศัตรู ให้เสียหัวใจครั้งเดียว แล้วอมตะกระพริบ ไม่โดนซ้ำรัว
เงื่อนไขชน/ตก→ลดชีวิต→Flash→กันซ้ำ
1

เตรียม Flash บน player

player → Behaviors
  1. ต้องมี Behavior Flash แล้ว (จากบท 3)
  2. จะใช้เงื่อนไข Is flashing (Invert) แทนตัวแปรอมตะ
Flash Duration ในเกมจริง = 3.0 วินาที · On/Off = 0.1
2

ตกนอกฉาก

game sheet → กลุ่ม “ตัวครละครออกจากฉาก”
player → Is outside layout
Flash → Is flashing (Invert)
System → Trigger once while true
Set position X=player.X , Y=700
Subtract 1 from พลังชีวิต
Flash (0.1 / 0.1 / Duration 3.0)

Y=700 ยกขึ้นเหนือพื้น — ปรับถ้าพื้นคนละระดับ

3

ชน eminy ด้านข้าง (สรุป — ละเอียดบท 8)

player → On collision with eminy
Sub-event Else + ไม่ Flash → ลดชีวิต · Vector X กระเด็น · Vector Y=-350 · Play hurt · Flash 3s

เหยียบหลังมอน (กำลังตก + Y สูงกว่า) = ทำลายมอน ไม่ลดหัวใจ — ดูบท 8

4

ทำไมต้อง Invert Is flashing?

ถ้าไม่เช็ค Flash → ยืนชนมอนจะลดหัวใจทุกเฟรมจนตายทันที
ระหว่างกระพริบ 3 วินาที เงื่อนไข Invert ทำให้ Event ดาเมจไม่ผ่าน
  1. อย่าใช้ Wait ใต้ Every tick เพื่อปลดอมตะ
  2. อย่าลืม Trigger once ตอนตกฉาก
ทดสอบก่อนไปบทถัดไป: ตกฉากเสีย 1 หัวใจ · Flash กระพริบ · ระหว่าง Flash ไม่เสียซ้ำ · ยกกลับขึ้นพื้น
