Object Families

รวม object หลายชนิดให้ Event สั้นลง

เป้าหมายบทนี้: สร้าง Family เพื่อจัดการมอน/กระสุนหลายชนิดด้วย Event ชุดเดียว
สร้าง Family→ใส่สมาชิก→Event กับ Family→ลด Event ซ้ำ
1

เมื่อไหร่ควรใช้ Family

แนวคิดก่อนลงมือ
มีมอนหลายสไปรต์แต่โดนดาเมจแบบเดียวกัน
มีกระสุนหลายชนิดแต่กฎชนผู้เล่นเหมือนกัน

ใน v32 ตอนนี้ใช้ eminy / emon_bullet ชนิดเดียว — Family พร้อมเมื่อขยายเกม

2

สร้าง Family

Project bar → คลิกขวา → Add family
  1. ชื่อ เช่น Enemies
  2. Add object types: eminy (และมอนชนิดใหม่ถ้ามี)
  3. สร้าง Bullets สำหรับกระสุน
3

Event กับ Family

player → On collision with Enemies
ใช้กฎเหยียบ/เจ็บเหมือนบท 08 แต่ไม่ต้องคัดลอกทีละชนิดมอน
player On collision Bullets → ลดชีวิต · Destroy
4

ข้อควรระวัง

Behavior ที่ใช้ร่วมต้องมีครบทุกสมาชิก (หรือเช็คก่อนเรียก)
Instance variable ชื่อเดียวกันถึงจะ Compare ผ่าน Family ได้สะดวก
