บทที่ 10 • โครงสร้างเกม

หน้าเมนูหลัก รับชื่อผู้เล่น และเลือกด่าน

รับชื่อผู้เล่นด้วย Textbox → ตรวจห้ามว่าง → ปุ่มเลือกด่าน 1–3 → ล็อกด่านที่ยังเล่นไม่ถึง

กรอกชื่อผู้เล่น:
สร้างหน้า Title→วาง Textbox→รับชื่อผู้เล่น→ตรวจห้ามว่าง→หน้าเลือกด่าน
1

สร้าง Layout "Title Menu"

สร้าง Layout ใหม่ชื่อ Title Menu พร้อม Event Sheet แยกต่างหาก

องค์ประกอบหน้าแรก:
• Logo / ชื่อเกม
• Textbox (สำหรับกรอกชื่อ)
• Button "เริ่มเล่น"
2

วาง Textbox รับชื่อ

แทรก Form Control → Textbox ตั้งชื่อว่า name_input

Properties:
Placeholder: "พิมพ์ชื่อผู้เล่น..."
Max length: 15
Font size: 20 px
3

บันทึกชื่อผู้เล่น

สร้าง Global Variable ชื่อ ชื่อผู้เล่น (Text) = ""

On Button "เริ่มเล่น" Clicked
name_input.Text ≠ ""
Set ชื่อผู้เล่น to name_input.Text
System → Go to layout "Level Select"
4

เตือนเมื่อไม่ได้พิมพ์ชื่อ

ถ้าช่องชื่อเป็นว่าง ให้แสดงข้อความเตือนและไม่ให้ผ่าน

On Button "เริ่มเล่น" Clicked
name_input.Text = ""
alert_text → Set text to "กรุณากรอกชื่อก่อนเล่น!"
Audio → Play "wrong"
5

หน้าเลือกด่าน (Level Select) และระบบล็อกด่าน

สร้าง Global Variable ด่านสูงสุด (Number) = 1

ปุ่มด่าน 1: กดแล้ว Go to layout "Level 1"
ปุ่มด่าน 2: ด่านสูงสุด ≥ 2 → ปลดล็อก | Else → ตั้งเป็นภาพแม่กุญแจ (Locked)
ปุ่มด่าน 3: ด่านสูงสุด ≥ 3 → ปลดล็อก | Else → ตั้งเป็นภาพแม่กุญแจ (Locked)
6

ปลดล็อกด่านเมื่อเล่นผ่าน

เมื่อผ่านด่าน 1 (เข้าประตู):
Set ด่านสูงสุด to max(ด่านสูงสุด, 2)
เมื่อผ่านด่าน 2:
Set ด่านสูงสุด to max(ด่านสูงสุด, 3)
รายการทดสอบ: ไม่พิมพ์ชื่อกดเริ่มเกมไม่ได้ • พิมพ์ชื่อแล้วชื่อบันทึกในตัวแปร • ด่าน 2 และ 3 ล็อกอยู่ในช่วงแรก • เล่นผ่านด่าน 1 แล้วด่าน 2 ปลดล็อกทันที
