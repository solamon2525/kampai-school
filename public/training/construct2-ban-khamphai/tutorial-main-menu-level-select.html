บทที่ 10 • โครงสร้างเกม

หน้าเมนูหลัก รับชื่อผู้เล่น และเลือกด่าน

รับชื่อผู้เล่นด้วย Textbox → ตรวจห้ามว่าง → ปุ่มเลือกด่าน 1–3 → ล็อกด่านที่ยังเล่นไม่ถึง

กรอกชื่อผู้เล่น:
สร้างหน้า Title→วาง Textbox→รับชื่อผู้เล่น→ตรวจห้ามว่าง→หน้าเลือกด่าน
1

Touch Plugin สำหรับเมนู

เพิ่ม Touch plugin และตั้ง Event สำหรับปุ่มใน title sheet

Touch → On touched object "play" → Go to layout "name"
Touch → On touched "btn_rank" → Go to layout "ranking"
Touch → On touched "Sprite5" → Go to layout "Howto"

📍 ที่ไหนใน C2: title sheet, Layout title

2

เล่นเพลง BGM ในหน้าแรก

เล่นเพลง OpeningTheme เมื่อเริ่มเกม

System → On start of layout
Audio → Play "OpeningTheme" looping
Tag: "bgm"

📍 ที่ไหนใน C2: title sheet

3

หยุดเพลงก่อนเปลี่ยนฉาก

ป้องกันเสียงเพลงซ้อนกัน

System → On end of layout
Audio → Stop tag "bgm"

📍 ที่ไหนใน C2: title sheet

4

หน้า name: รับชื่อผู้เล่น

รับชื่อด้วย TextBox input_name

Touch → On touched btn_ok (หรือ Keyboard → On Key Pressed (Enter 13))
Set ชื่อผู้เล่น to input_name.Text
System → Go to layout "select"

📍 ที่ไหนใน C2: name sheet

5

หน้า select: เลือกระดับด่าน

ปิดปุ่มด่านที่ยังเล่นไม่ถึงโดยเช็คจากตัวแปร ผ่านด่านN

System → Compare ผ่านด่าน1 = 1 → เปิดด่าน 2
Else → ลด Opacity ปุ่มด่าน 2 หรือ Disable ปุ่ม

📍 ที่ไหนใน C2: select sheet

6

⚠️ ข้อผิดพลาดที่พบบ่อย

ปุ่มกดไม่ติดบนมือถือ

สาเหตุ: ใช้ Mouse plugin แทน Touch
วิธีแก้: ใช้ Touch plugin (On touched object) เสมอ เพื่อรองรับทั้งมือถือและคอม

📍 ที่ไหนใน C2: ทุก Event Sheet ที่มีปุ่ม

รายการทดสอบ: กดปุ่มในหน้า title ติดด้วย Touch • เพลง OpeningTheme เล่นวนลูป (Tag bgm) • เพลงหยุดเมื่อเปลี่ยน Layout • กรอกชื่อแล้วกดปุ่ม OK หรือปุ่ม Enter (13) เพื่อไปหน้า select ได้ • ด่านที่ยังไม่ผ่านจะถูกลด opacity หรือกดไม่ได้
