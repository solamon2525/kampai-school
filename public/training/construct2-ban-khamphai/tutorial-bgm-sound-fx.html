บทที่ 12 • เสียงและดนตรี

ระบบเสียงดนตรีประกอบและเอฟเฟกต์

เพิ่ม Audio Plugin → เล่นเพลง BGM วนลูป → หยุดเพลงเก่าก่อนสลับฉาก → เสียงเอฟเฟกต์ปุ่ม/ต่อสู้

🎵 BGM: Level_Theme (Loop)
🔊 Sound FX: Jump / Hurt / Correct
เพิ่ม Audio→นำเข้าไฟล์ WAV/OGG→เล่น BGM บน Start→เล่น FX เมื่อมีแอ็กชัน→Stop ก่อนย้ายฉาก
1

เพิ่ม Audio Object

ดับเบิลคลิกพื้นที่ว่าง → เลือก Media → Audio

นำเข้าไฟล์เสียงใน Project Bar:
• โฟลเดอร์ Music (สำหรับเพลงยาว BGM)
• โฟลเดอร์ Sounds (สำหรับเอฟเฟกต์สั้น)
2

เล่นเพลง BGM เมื่อเริ่มด่าน

สั่งให้เล่นเพลงประจำด่านใน On start of layout

System → On start of layout
Audio → Play "bgm_level1" (looping)
Volume: -6 dB • Tag: "bgm"

เบาเพลง BGM ลงเล็กน้อย (-6 dB) เพื่อไม่ให้เสียงดังกลบเอฟเฟกต์

3

เล่นเสียงเอฟเฟกต์ (Sound FX)

สั่งเล่นเสียงเมื่อผู้เล่นกระโดดหรือเก็บไอเทม

player.Platform → On jump
Audio → Play "jump_sfx" (not looping)
player → On collision with coin
Audio → Play "coin_sfx" (not looping)
4

เสียงตอบโจทย์ถูกต้อง/ผิด

เสริมสร้างแรงจูงใจในการเรียนรู้ด้วยเสียงตอบรับ

เมื่อเลือกคำตอบถูก:
Audio → Play "correct_chime"
เมื่อเลือกคำตอบผิด:
Audio → Play "wrong_buzz"
5

ป้องกันเสียงเพลงซ้อนกันเมื่อเปลี่ยน Layout

ก่อนเปลี่ยน Layout (เช่น สลับไปด่าน 2 หรือ Game Over):
Audio → Stop "bgm" (หรือ Stop all)

หากไม่สั่งหยุด เพลงจาก Layout เดิมจะเล่นซ้อนทับกับเพลงใหม่ของ Layout ถัดไป

6

ปุ่มเปิด–ปิดเสียง (Mute / Unmute Toggle)

เมื่อกดปุ่ม ลำโพง บน HUD:
System → Toggle Global Variable เปิดเสียง
เปิดเสียง = 0 → Audio → Set master volume to -100 dB (Mute)
เปิดเสียง = 1 → Audio → Set master volume to 0 dB (Unmute)
รายการทดสอบ: เพลงเริ่มเล่นทันทีเมื่อเข้าด่าน • เล่นวนลูปไม่สะดุด • เสียงกระโดดและเก็บเหรียญเล่นครั้งเดียว • สลับด่านแล้วเพลงเดิมหยุด • ปุ่ม Mute ปิดเสียงได้จริง
