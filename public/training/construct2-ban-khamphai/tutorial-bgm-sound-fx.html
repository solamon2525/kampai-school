บทที่ 12 • เสียงและดนตรี

ระบบเสียงดนตรีประกอบและเอฟเฟกต์

เพิ่ม Audio Plugin → เล่นเพลง BGM วนลูป → หยุดเพลงเก่าก่อนสลับฉาก → เสียงเอฟเฟกต์ปุ่ม/ต่อสู้

🎵 BGM: Level_Theme (Loop)
🔊 Sound FX: Jump / Hurt / Correct
เพิ่ม Audio→นำเข้าไฟล์ WAV/OGG→เล่น BGM บน Start→เล่น FX เมื่อมีแอ็กชัน→Stop ก่อนย้ายฉาก
1

ระบบ Tag สำหรับเพลง

เปิดเพลงโดยใช้ Tag เพื่อง่ายต่อการควบคุม

System → On start of layout
Audio → Play "OpeningTheme" (looping)
Tag: "bgm"

📍 ที่ไหนใน C2: title sheet, Layout title

2

หยุดเพลงก่อนเปลี่ยนฉาก

ป้องกันเสียงเพลงซ้อนกัน

System → On end of layout
Audio → Stop tag "bgm" (หรือ Stop all)

📍 ที่ไหนใน C2: title sheet, Layout title

3

เล่นเสียงเอฟเฟกต์ (Sound FX)

สั่งเล่นเสียงเมื่อผู้เล่นกระโดดหรือเก็บไอเทม

player.Platform → On jump
Audio → Play "jump_sfx" (not looping)

📍 ที่ไหนใน C2: game sheet

4

⚠️ ข้อผิดพลาดที่พบบ่อย

เพลงของด่านเดิมเล่นซ้อนกับด่านใหม่

สาเหตุ: ลืมใช้ Audio Stop หรือ Stop tag "bgm" ก่อน Go to layout
วิธีแก้: ใส่ On end of layout → Stop tag "bgm" เสมอ

📍 ที่ไหนใน C2: title sheet, Layout title

รายการทดสอบ: เพลงเริ่มเล่นทันทีและมี Tag "bgm" • เล่นวนลูปไม่สะดุด • สลับด่านแล้วเพลงเดิมหยุด (On end of layout -> Stop bgm) • เสียงเอฟเฟกต์ไม่ถูกตัด
