บทที่ 16 • การเผยแพร่เกม

การ Export และเปิดเล่นบนเว็บ

Export โปรเจกต์เป็น HTML5 Website → ตรวจโครงสร้างไฟล์ → นำเข้าสู่ระบบ Kampai School → เปิดเล่นได้จริง

📦 Export HTML5 Website (Zip / Folder)
🌐 Deploy to Kampai School Portal
File ➔ Export→เลือก HTML5 Website→ตรวจไฟล์ Build→ลงคลังสื่อ Kampai→เปิดเล่นบนเว็บ
1

ขั้นตอน Export จาก Construct 2

ไปที่เมนู File → Export project

เลือก Target:
HTML5 Website (สำหรับเว็บเบราว์เซอร์ทั่วไป)
แล้วกด Next เพื่อเลือกโฟลเดอร์ปลายทาง
2

การตั้งค่า Export Options

ปรับแต่งเพื่อให้เกมมีขนาดเล็กและโหลดเร็ว

Minify script: Enabled (Yes)
PNG compression: Brute force
Re-compress images: Yes
3

ตรวจสอบโครงสร้างไฟล์ Build

ในโฟลเดอร์หลัง Export ต้องมีไฟล์ครบดังนี้:

• `index.html`
• `c2runtime.js`
• `jquery-3.x.min.js`
• โฟลเดอร์ `images/` และ `media/`
4

นำเข้าโฟลเดอร์ระบบ Kampai School

คัดลอกไฟล์ทั้งหมดไปวางไว้ที่:

`public/games/{วิชา}/{ชื่อเกม}/`

เช่น `public/games/math/red-hood-math/`

5

การลงทะเบียนเกมลงในคลังสื่อ (educational_hub_items)

สร้าง SQL Seed Migration: `supabase/migrations/NNN_seed_game.sql`
INSERT INTO educational_hub_items (title, game_slug, item_type, external_url, ...)
INSERT INTO game_docs (item_id, format, features, build_version, ...)

เพื่อให้เกมปรากฏในคลังสื่อการศึกษาของครูและนักเรียนทันที

6

ทดสอบการเล่นผ่านบราวเซอร์จริง

รันคำสั่งตรวจสอบสเปกเกม:
pnpm verify:game public/games/{subject}/{slug}

ต้องผ่านการตรวจสอบทั้งภาพปก 16:9 สคริปต์ และการเรนเดอร์ในบราวเซอร์

รายการทดสอบ: Export สำเร็จไม่มีไฟล์ขาดหาย • เกมเปิดเล่นในเบราว์เซอร์คอมพิวเตอร์และมือถือได้ • ปุ่มและสัมผัสตอบสนองลื่นไหล • โหลดภาพและเสียงครบถ้วน • ผ่าน verify:game 9/9 ข้อ
