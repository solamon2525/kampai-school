บทที่ 5 • ระบบมอนสเตอร์

เดินลาดตระเวนและหันหน้าตามทิศทาง

เดินซ้าย–ขวาในเขตของตัวเอง • ระยะเดินสุ่ม • กลับภาพด้วย Mirrored โดยไม่กลับหัว

ขอบซ้ายเขตลาดตระเวนขอบขวา
←
👾
→
จำจุดเริ่ม→สุ่มระยะ→เดิน→ถึงขอบ→กลับทิศ
1

เพิ่มตัวแปรให้ monster

เลือก monster → Instance variables

จุดเริ่มX • Number • 0
ระยะเดิน • Number • 300
ทิศทาง • Number • 1
ความเร็ว • Number • 80

ทิศทาง 1 = ขวา และ −1 = ซ้าย

2

กำหนดค่าเมื่อสร้าง

ใช้ On created เพื่อให้มอนสเตอร์แต่ละตัวมีค่าของตัวเอง

monster → On created
Set จุดเริ่มX to monster.X
Set ระยะเดิน to random(220, 480)
Set ความเร็ว to random(60, 100)

วาง monster คนละจุดได้ โดยไม่ต้องสร้าง Event แยกแต่ละตัว

3

เดินทุกเฟรม

อัปเดตตำแหน่งด้วย dt เพื่อให้เร็วเท่ากันทุกเครื่อง

System → Every tick
monster → Set X to
monster.X + monster.ความเร็ว × monster.ทิศทาง × dt

dt คือเวลาของหนึ่งเฟรม ห้ามตัดออก มิฉะนั้นความเร็วขึ้นกับ FPS

4

ถึงขอบขวาให้กลับซ้าย

monster.X ≥ monster.จุดเริ่มX + monster.ระยะเดิน
Set ทิศทาง to −1
Set X to จุดเริ่มX + ระยะเดิน

Set X ซ้ำที่ขอบ ป้องกันมอนสเตอร์เลยเขตเมื่อเฟรมกระตุก

5

ถึงขอบซ้ายให้กลับขวา

monster.X ≤ monster.จุดเริ่มX − monster.ระยะเดิน
Set ทิศทาง to 1
Set X to จุดเริ่มX − ระยะเดิน

เขตเดินจึงกว้างรวมสองด้าน = ระยะเดิน × 2

6

หันหน้าตามทิศ

monster.ทิศทาง = 1
Set mirrored: Not mirrored
monster.ทิศทาง = −1
Set mirrored: Mirrored

ถ้าภาพต้นฉบับหันซ้าย ให้สลับ Mirrored สองบรรทัดนี้

7

ป้องกันเดินตกขอบเกาะ

วาง Sprite ล่องหนชื่อ monster_turn ที่ปลายเกาะทั้งสองด้าน แล้วปิด Visible

monster → On collision with monster_turn
monster → Set ทิศทาง to monster.ทิศทาง × −1

วิธีนี้ปลอดภัยกว่าพึ่งระยะ X อย่างเดียวสำหรับมอนสเตอร์บนเกาะสั้นหรือเกาะเคลื่อนที่

8

Animation เดินและหยุด

monster.ความเร็ว > 0 → Set animation "Walk"
Else → Set animation "Idle"

ตั้ง Walk ให้ Loop และเลือก Play from current frame เพื่อไม่ให้แอนิเมชันเริ่มเฟรมแรกซ้ำทุก Tick

รายการทดสอบ: มอนสเตอร์แต่ละตัวมีระยะและความเร็วต่างกัน • ไม่เดินออกนอกเขต • ถึงปลายเกาะแล้วกลับ • หัวหันไปทางที่เดิน • ไม่กลับหัว • ความเร็วคงที่เมื่อ FPS เปลี่ยน
