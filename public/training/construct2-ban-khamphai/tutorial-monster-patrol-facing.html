บทที่ 6 • ระบบมอนสเตอร์

เดินลาดตระเวนและหันหน้าตามทิศทาง

เดินซ้าย–ขวาในเขตของตัวเอง • ระยะเดินสุ่ม • กลับภาพด้วย Mirrored โดยไม่กลับหัว

ขอบซ้ายเขตลาดตระเวนขอบขวา

👾
→
จำจุดเริ่ม→สุ่มระยะ→เดิน→ถึงขอบ→กลับทิศ
1

เดินด้วย Sine Behavior

เลือก Sprite eminy แล้วเพิ่ม Behavior

eminy → Behaviors → Add Sine
Movement: Horizontal
Wave: Sine
Period: 4 (สุ่มค่า 3-6 ได้เพื่อให้เดินไม่พร้อมกัน)
Magnitude: 150 (ระยะการเดินซ้ายขวา)

Sine จะทำให้มอนสเตอร์เดินแกว่งซ้าย-ขวาอัตโนมัติ โดยไม่ต้องเขียนโค้ดคำนวณตำแหน่งเอง

📍 ที่ไหนใน C2: Layout → Layer game

2

ตัวแปรจำตำแหน่งเดิม

เพิ่ม Instance variable ให้ eminy เพื่อเอาไว้เทียบว่าเดินไปทางไหน

eminy → Instance variables
Name: ตำแหน่งXก่อนหน้า
Type: Number • Initial: 0

ตัวแปรนี้จะใช้เก็บตำแหน่งของเฟรมที่แล้ว เพื่อเอามาเทียบกับเฟรมปัจจุบัน

📍 ที่ไหนใน C2: Properties ของ eminy

3

หันหน้าตามทิศเดิน (ซ้าย-ขวา)

System → Every tick
eminy → Compare X: > eminy.ตำแหน่งXก่อนหน้า → Set mirrored: Not mirrored
eminy → Compare X: < eminy.ตำแหน่งXก่อนหน้า → Set mirrored: Mirrored
eminy → Set ตำแหน่งXก่อนหน้า to eminy.X

อัปเดต ตำแหน่งXก่อนหน้า ไว้ท้ายสุดเสมอ เพื่อใช้เปรียบเทียบในรอบถัดไป

📍 ที่ไหนใน C2: game sheet → กลุ่ม "มอนสเตอร์หันหน้าตามทิศเดิน"

4

สุ่มวางในด่าน 2 และ 3

ใน Layout game2 และ game3 คุณสามารถสุ่มวาง eminy ตามเกาะต่างๆ ได้อย่างอิสระ

Tip: ปรับค่า Period (ความเร็วการเดิน) และ Magnitude (ระยะเดิน) ในหน้า Properties ของแต่ละตัวให้ไม่เท่ากัน เพื่อให้เกมดูเป็นธรรมชาติ

📍 ที่ไหนใน C2: Layout game2 และ game3

⚠️ ข้อผิดพลาดที่พบบ่อย

- ลืมใส่คำสั่งอัปเดตค่า `ตำแหน่งXก่อนหน้า` ไว้บรรทัดสุดท้าย (ต้องอยู่หลังจากการตรวจสอบทิศทางเสมอ)
- ตั้ง Magnitude ของ Sine มากเกินไปจนมอนสเตอร์เดินตกขอบเกาะ
รายการทดสอบ: มอนสเตอร์เดินซ้าย-ขวาอัตโนมัติบนเกาะ • หัวหันไปทางที่เดินเสมอไม่ว่าเดินไปทางไหน • แต่ละตัวบนจอเดินด้วยความเร็วหรือระยะทางที่ต่างกัน (ถ้าสุ่มค่าไว้)
