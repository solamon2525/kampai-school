บทที่ 4 · เฟส B · เลือด · ทำตามทีละขั้น

หัวใจ 5 ดวง

ตัวแปร พลังชีวิต · heart.index · HUD

เป้าหมายบทนี้: ให้หัวใจบน HUD ลดตามค่า พลังชีวิต และหายเมื่อเสียชีวิต
ตัวแปร→วาง heart→ตั้ง index→Event โชว์/ซ่อน
1

สร้างตัวแปร Global

game sheet → คลิกขวาพื้นที่ว่าง
  1. Add global variable
  2. ชื่อ พลังชีวิต · Type Number · Initial 5
On start of layout (กลุ่มเริ่มด่าน):
System → Set พลังชีวิต to 5
2

วาง heart บน HUD

Layout game → Layer HUD
  1. วาง Sprite heart 5 อัน มุมบนซ้าย
  2. แต่ละอัน → Instance variables → Add index (Number)
  3. ตั้งค่า index = 0, 1, 2, 3, 4 ตามลำดับจากซ้าย

index ต้องต่อเนื่องเริ่ม 0 — ห้ามซ้ำ

3

Event โชว์หัวใจที่ยังมี

game sheet → กลุ่ม “ระบบหัวใจ HUD”
System → Every tick
heart → Compare instance variable index < พลังชีวิต
heart → Set visible

ตัวอย่าง: พลังชีวิต=3 → โชว์หัวใจ index 0,1,2

4

Event ซ่อนหัวใจที่หมด

Every tick
heart.index ≥ พลังชีวิต
heart → Set invisible

อยากได้ 3 หัวใจ: วาง 3 อัน index 0–2 และตั้งค่าเริ่ม พลังชีวิต=3

5

ผิดพลาดที่พบบ่อย

หัวใจไม่หาย → ลืมตั้ง index · หรือเปรียบเทียบผิดทิศ
หัวใจเลื่อนตามกล้อง → วางผิด Layer (ต้องอยู่ HUD)
ลดชีวิตแล้วไม่จบเกม → ดูบท 5/8 เรื่อง พลังชีวิต ≤ 0
ทดสอบก่อนไปบทถัดไป: เริ่ม 5 ดวง · ลดเหลือ 3 แล้วยังโชว์ 3 · เหลือ 0 แล้วหัวใจหายหมด
