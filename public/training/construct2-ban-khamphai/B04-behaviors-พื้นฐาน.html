Behaviors พื้นฐาน

Solid · Platform · Scroll To · Bullet · Sine · Flash

เป้าหมายบทนี้: ใส่ Behavior ให้ object แล้วทดลองเคลื่อนไหว/ชนโดยยังไม่เขียน Event ยาว
เลือก object→Add behavior→ตั้งค่า→F5
1

Solid / Jump-thru

object พื้น / เกาะ → Behaviors
Solid = พื้นยืนและชนด้าน
Jump-thru = เกาะทะลุจากล่าง
2

Platform + Scroll To

player → Behaviors
Platform Default controls = Yes
Max jumps / Jump strength / Gravity
Scroll To = กล้องตามผู้เล่น
3

Bullet / Sine / Flash

Bullet = กระสุนพุ่งตามมุม
Sine = มอน/เกาะลอยซ้ายขวา
Flash = กระพริบอมตะหลังโดนดาเมจ

Destroy outside layout คู่กับ Bullet จะหายเมื่อพ้นจอ

4

ตารางจำ Behavior ใน Red Hood

player = Platform + Scroll To + Flash
TiledBackground2 = Solid · sky = Jump-thru
eminy = Sine · emon_bullet = Bullet + Destroy outside
5

ทดสอบ

  1. พื้น Solid แล้วเดินไม่ตก
  2. Platform เดินกระโดดได้
  3. Scroll ตามตัวละคร
