ตัวแปร Global และ Instance

Global Variable • Instance Variable • Set • Add • Subtract

1

Global Variable

ค่าที่ใช้ร่วมทุก Layout ในเกม เช่น คะแนน (Number = 0), ชื่อผู้เล่น (Text = "").
1. คลิกขวา พื้นที่ว่างใน Event sheet
2. เลือก Add global variable
3. ตั้งชื่อในช่อง Name เช่น Score
4. Type เลือก Number หรือ Text, และกำหนด Initial value (ค่าเริ่มต้น)

📍 ที่ไหนใน C2: Event sheet → คลิกขวา → Add global variable

2

Instance Variable

ค่าที่ติดตัวอยู่กับ object แต่ละตัว เช่น heart.index (แต่ละหัวใจมี index 0-4 ต่างกัน)
1. คลิกเลือก Object (เช่น heart)
2. ในหน้าต่าง Properties มองหาหมวด Instance variables แล้วคลิก
3. คลิกไอคอน + (Add new instance variable)
4. ตั้งชื่อตัวแปร เช่น index และ Type เป็น Number

Instance Variables
index0

📍 ที่ไหนใน C2: เลือก object → Properties → Instance variables

3

Set / Add / Subtract

การแก้ไขตัวแปร เช่น การเก็บของแล้วได้คะแนนเพิ่ม:
1. สร้าง Event: player → On collision with another object → star
2. สร้าง Action:
- star → Destroy
- System → Add to (เลือกตัวแปร Score, Value: 10)
- Text → Set text (พิมพ์ "คะแนน : " & Score)

player ➔ On collision with star
star ➔ Destroy
System ➔ Add 10 to Score
Text ➔ Set text to "คะแนน : " & Score

ใช้ Set value = กำหนดค่าใหม่ทับไปเลย, Add to = บวกเพิ่ม, Subtract from = ลบออก.

📍 ที่ไหนใน C2: Action → System → Set/Add/Subtract

4

แสดงค่าบน HUD ด้วย Text

1. ไปที่เลเยอร์ HUD (คลิกที่แท็บ Layers)
2. ดับเบิลคลิก พื้นที่ว่าง → Insert Text
3. วางบนตำแหน่งที่ต้องการ เช่น มุมบนซ้าย
4. สร้าง Event อัปเดตตลอดเวลา:
- Condition: System → Every tick
- Action: Text → Set text เป็น "คะแนน : " & Score

System ➔ Every tick
Text ➔ Set text to "คะแนน : " & Score

📍 ที่ไหนใน C2: Layer HUD → Insert → Text

5

⚠️ ข้อผิดพลาดที่พบบ่อย

  • พิมพ์ชื่อตัวแปรผิด (C2 ไม่มี autocomplete ควรก๊อปปี้ชื่อมาวาง)
  • สับสน Instance กับ Global (Instance ติดตัว object ใช้แยกกัน, Global ใช้ร่วมทุกที่)
  • เปลี่ยนค่าตัวแปร (Add คะแนน) แล้วลืมอัปเดต Text บน HUD ทำให้คะแนนขึ้นแต่หน้าจอไม่เปลี่ยน
