บทที่ 11 • ระบบเวลาและคะแนน

ระบบเวลานับถอยหลังและคะแนนสะสม

ตั้งเวลานับถอยหลัง 180 วินาที → แปลงเป็น นาที:วินาที → เพิ่มคะแนนสะสม → เวลาหมดเข้า Game Over

⏱️ เวลา: 02:45
⭐ คะแนน: 1,250
ตั้งเวลา 180 วินาที→ลดทุก 1 วินาที→แปลง format นาที:วิ→บวกคะแนน→หมดเวลา = แพ้
1

สร้างตัวแปรเวลาและคะแนน

เพิ่ม Global Variables ใน Event Sheet

เวลาคงเหลือ • Number • 180
คะแนนรวม • Number • 0
2

นับถอยหลังทุก 1 วินาที

ใช้คำสั่ง System → Every 1 second

System → Every 1 second
Subtract 1 from เวลาคงเหลือ

หรือใช้ `dt` หักลบทุกเฟรมสำหรับนาฬิกาที่ต้องการความละเอียดทศนิยม

3

แปลงรูปแบบเป็น นาที : วินาที

คำนวณและแสดงผลบน Text Object ชื่อ timer_text

timer_text → Set text to
"⏱️ " & zeropad(floor(เวลาคงเหลือ / 60), 2) &
":" & zeropad(เวลาคงเหลือ % 60, 2)

`zeropad(N, 2)` จะเติมเลข 0 ด้านหน้าหากค่าน้อยกว่า 10 เช่น `05:09`

4

เพิ่มคะแนนสะสม

เมื่อเก็บเหรียญ หรือตอบโจทย์คณิตถูกต้อง

player → On collision with coin
Add 100 to คะแนนรวม
coin → Destroy
Audio → Play "coin"
5

เวลาหมด ตัดเข้าสู่ Game Over

System → Compare เวลาคงเหลือ ≤ 0
System → Trigger once
player.Platform → Set enabled: Disabled
Audio → Play "time_up"
Wait 1.5 seconds → Go to layout "Game Over"
6

คำนวณโบนัสเวลาเมื่อจบด่าน

เมื่อผู้เล่นเดินเข้าประตูผ่านด่าน:
Add (เวลาคงเหลือ × 10) to คะแนนรวม

ยิ่งเหลือเวลามาก ยิ่งได้โบนัสคะแนนเพิ่มขึ้นเป็นรางวัลแก่นักเรียน

รายการทดสอบ: เวลาเริ่มที่ 03:00 และลดทีละวิ • รูปแบบนาที:วินาทีถูกต้อง • เวลาเหลือน้อยกว่า 10 วินาทีมี 0 นำหน้า • เก็บเหรียญแล้วคะแนนเพิ่ม • หมดเวลาตัดเข้า Game Over ครั้งเดียว
