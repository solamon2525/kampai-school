บทที่ B1 • พื้นฐาน Construct 2

ติดตั้ง Construct 2 และรู้จักหน้าจอ

ดาวน์โหลด • ติดตั้ง • หน้าต่างการทำงาน • การสร้างโปรเจกต์ใหม่

1 ดาวน์โหลดและติดตั้ง

โหลด Construct 2 r280 (Free Edition) จากเว็บ Scirra.com แล้วติดตั้งตามขั้นตอน โดยเลือก Typical → Next → Finish.

📍 ที่ไหนใน C2: Windows → ไฟล์ติดตั้ง .exe

2 หน้าจอหลัก 3 ส่วน

ซ้าย: Project bar (รายการ object, layout, event sheet)
กลาง: Layout view (วาดฉาก วางวัตถุ)
ขวา: Properties (แก้ค่าต่างๆ ของ object)

📍 ที่ไหนใน C2: หลังเปิดโปรแกรม Construct 2 จะเห็นทันที

3 สร้างโปรเจกต์แรก

เลือก File → New → Empty project, ตั้งชื่อใน Properties, ตั้ง Window size เป็น 1280×720 หรือ 1500×960. บันทึกงาน (Save as .capx).
เวลาต้องการทดสอบเกม ให้กดปุ่ม F5 เพื่อ Preview ในบราวเซอร์

📍 ที่ไหนใน C2: เมนู File → New

4 รู้จัก Layout กับ Event Sheet

Layout คือ ฉากเกม (สำหรับวาดฉาก วางตัวละคร)
Event Sheet คือ สมองของเกม (สำหรับสั่งงานและใส่โค้ด)
ทุก Layout จะมี Event Sheet คู่กันเสมอ เพื่อให้ทำงานสอดคล้องกัน

📍 ที่ไหนใน C2: แถบ Project bar (ซ้าย) → โฟลเดอร์ Layouts / Event sheets

⚠️ ข้อผิดพลาดที่พบบ่อย

  • ติดตั้ง C2 ไม่สำเร็จ: ให้ลองคลิกขวาที่ไฟล์ติดตั้งแล้วรันแบบ Run as administrator
  • เปิดไฟล์ .capx แล้ว C2 ไม่ขึ้น: ตรวจสอบเวอร์ชันของ Construct 2 ว่าตรงกันหรือไม่
  • กด F5 แล้วจอดำ: เพราะยังไม่มี object ใน Layout ลองใส่ Sprite สักตัวก่อน
  • ลืม Save as: งานอาจหายเมื่อไฟดับ หมั่นเซฟงานเรื่อยๆ
✅ รายการทดสอบ: เปิด C2 ได้ • สร้างโปรเจกต์ใหม่ได้ • รู้แถบซ้าย/กลาง/ขวา • กด F5 แล้วขึ้นหน้าต่าง Preview
คู่มือ Construct 2 สำหรับผู้เริ่มต้น • ติดตั้งและหน้าจอ งานถัดไป: สร้าง Sprite และ Animation
