บทที่ 6 • ระบบโจมตีของมอนสเตอร์

ตรวจจับและยิงกระสุนหาผู้เล่นอัตโนมัติ

ยิงจากปาก • สุ่มทุก 10–20 วินาที • จำกัดมุม 30° • กระสุนไปจนพ้นจอ

นัดถัดไป: สุ่ม 10–20 วิ
มุมยิงไม่เกิน ±30°
🏃
🔥
👾
จับเวลา→เห็นผู้เล่น→สร้างที่ปาก→เล็ง→ยิง→ลบพ้นจอ
1

เตรียมวัตถุกระสุน

สร้าง Sprite ชื่อ enemy_bullet และวางไว้ใน Layout อย่างน้อย 1 ตัว

enemy_bullet → Behaviors
Add Bullet
Speed: 650
Set angle: Yes

วางตัวต้นแบบไว้นอกฉากและปิด Initial visibility เพื่อป้องกัน error “no instances”.

2

สร้างจุดปาก

เพิ่ม Image point ใน Sprite monster

เปิด Image editor
Set origin and image points
เพิ่ม Image point 1 ที่ปาก

ต้องกำหนดจุดปากครบทุกเฟรมของ Animation Walk/Idle

3

เพิ่มตัวแปรเวลายิง

เพิ่ม Instance variable ให้ monster

เวลายิงถัดไป • Number • 0
พร้อมยิง • Number • 0

On created → Set เวลายิงถัดไป to random(10,20)

แต่ละตัวจึงยิงคนละเวลา ไม่ยิงพร้อมกันทั้งฉาก

4

นับเวลาแบบง่าย

System → Every tick
monster → Subtract dt from เวลายิงถัดไป
เวลายิงถัดไป ≤ 0
Set พร้อมยิง to 1

ใช้ dt เพื่อให้นับวินาทีจริง ไม่ขึ้นกับจำนวนเฟรมต่อวินาที

5

ตรวจระยะและสร้างกระสุนจากปาก

monster.พร้อมยิง = 1
System → distance(monster.X, monster.Y, player.X, player.Y) ≤ 1200
System → Create enemy_bullet on layer "Game" at monster.ImagePointX(1), monster.ImagePointY(1)

ระยะ 1200 px ช่วยไม่ให้มอนสเตอร์ที่อยู่ไกลนอกจอยิงโดยไม่จำเป็น

6

เล็งผู้เล่นและจำกัดมุม ±30°

หลัง Create ใช้ angle() หาเป้าหมาย และ clamp จำกัดมุมยิงรอบทิศที่ monster หันอยู่

monster.ทิศทาง = −1 → ฐานมุม = 180
Else → ฐานมุม = 0
enemy_bullet → Set angle toward (player.X, player.Y)

แบบมือใหม่: ตรวจ angle(enemy_bullet.X, enemy_bullet.Y, player.X, player.Y) อยู่ในช่วงฐานมุม ±30 ก่อน Create; ถ้าเกินช่วงให้งดนัดนั้น

7

ตั้งเวลานัดถัดไป

ต่อจาก Event ยิงสำเร็จ
Set พร้อมยิง to 0
Set เวลายิงถัดไป to random(10,20)
Audio → Play "shoot"

ตั้งเวลาใหม่หลังยิง ไม่ใช้ Every X seconds เพราะต้องการช่วงสุ่ม

8

ลบกระสุนเมื่อพ้นจอ

enemy_bullet → Is outside layout
enemy_bullet → Destroy

player collision enemy_bullet
Destroy enemy_bullet

ป้องกันจำนวนกระสุนสะสมจนเกมช้า และลูกเดิมหักหัวใจซ้ำ

รายการทดสอบ: กระสุนเกิดตรงปากทุก Animation • ยิงคนละเวลา 10–20 วิ • ไม่ยิงเมื่อผู้เล่นอยู่นอกระยะ/เกินมุม • ความเร็ว 650 • เล็งตำแหน่งผู้เล่นขณะยิง • พ้น Layout หรือชนแล้วถูก Destroy
