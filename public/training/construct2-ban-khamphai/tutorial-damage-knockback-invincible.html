บทที่ 5 • ระบบต่อสู้พื้นฐาน

รับความเสียหาย กระเด็น และอมตะชั่วคราว

ลดหัวใจครั้งเดียว • กระเด็นออกจากศัตรู • กระพริบ 1.5 วินาที • ไม่โดนซ้ำรัว

อมตะ 1.5 วินาที

ชนศัตรู→ลดหัวใจ→กระเด็น→อมตะ→กลับปกติ
1

สร้างตัวแปรสถานะ

คลิกขวา Event Sheet → Add global variable

หัวใจ • Number • 5
เป็นอมตะ • Number • 0

0 = รับความเสียหายได้, 1 = อยู่ในช่วงป้องกันการโดนซ้ำ

2

ชนมอนสเตอร์

ตรวจทั้งการชนและสถานะอมตะก่อนลดหัวใจ

player → On collision with monster
System → Compare เป็นอมตะ = 0
Subtract 1 from หัวใจ
Set เป็นอมตะ to 1

ไม่จำเป็นต้องใช้ Trigger once เพราะตัวแปรอมตะล็อกเหตุการณ์ทันที

3

กระเด็นแนวนอน

เปรียบเทียบตำแหน่งของ player กับมอนสเตอร์

player.X < monster.X
Set Platform vector X to −450
Else
Set Platform vector X to 450

ค่าติดลบกระเด็นซ้าย ค่าบวกกระเด็นขวา

4

กระเด็นขึ้นและเล่นเสียง

ใส่ Actions ต่อจากการชนทั้งสองทิศ

player.Platform → Set vector Y to −420
Audio → Play "hurt" (not looping)
player → Flash for 1.5 seconds

ใน Construct 2 แกน Y ติดลบคือเคลื่อนขึ้นด้านบน

5

โดนกระสุน ใช้กฎเดียวกัน

player → On collision with enemy_bullet + เป็นอมตะ = 0
Subtract 1 from หัวใจ • Set เป็นอมตะ to 1 • Play "hurt"
player → Set vector X to sign(player.X − enemy_bullet.X) × 450
Set vector Y to −420 • enemy_bullet → Destroy

ถ้าต้องการ Event แบบง่ายมาก ให้แยกเงื่อนไข player อยู่ซ้าย/ขวาเหมือนขั้นตอนที่ 3 แทนสูตร sign()

6

ปลดอมตะหลัง 1.5 วินาที

หลัง Action รับความเสียหาย
System → Wait 1.5 seconds
System → Set เป็นอมตะ to 0

สำคัญ: วาง Wait ไว้ใต้ Event ที่ตั้งค่าอมตะเท่านั้น อย่าวางใต้ Every tick มิฉะนั้นจะสร้างคำสั่งรอจำนวนมาก

7

หัวใจหมดแล้ว Game Over

System → Compare หัวใจ ≤ 0
System → Trigger once
player → Set Platform enabled: Disabled
Wait 1 second → Go to layout "Game Over"

ปิดการควบคุมก่อนเปลี่ยนฉาก เพื่อไม่ให้ผู้เล่นยังเดินหรือกระโดดระหว่างแพ้

รายการทดสอบ: ยืนชนมอนสเตอร์ต้องลดเพียง 1 • กระเด็นออกจากด้านที่ชน • กระพริบ 1.5 วินาที • ระหว่างกระพริบไม่เสียหัวใจ • กระสุนหายหลังชน • หัวใจ 0 เข้า Game Over ครั้งเดียว
Construct 2 สำหรับผู้เริ่มต้น • Damage และ Knockbackงานถัดไป: มอนสเตอร์เดินลาดตระเวนและกลับตัว
