บทที่ 5 • ระบบต่อสู้พื้นฐาน

รับความเสียหาย กระเด็น และอมตะชั่วคราว

ลดหัวใจครั้งเดียว • กระเด็นออกจากศัตรู • กระพริบ 1.5 วินาที • ไม่โดนซ้ำรัว

1

สร้างตัวแปรสถานะ

คลิกขวา Event Sheet → Add global variable

หัวใจ • Number • 5
เป็นอมตะ • Number • 0

0 = รับความเสียหายได้, 1 = อยู่ในช่วงป้องกันการโดนซ้ำ

2

เหยียบมอนสเตอร์ (Stomp)

player → On collision with eminy
player.Platform → Is falling
System → Compare two values: player.Y ≤ eminy.Y − 10
eminy → Destroy
player.Platform → Set vector Y to −650
System → Add 50 to คะแนน

ถ้าผู้เล่นกำลังตกลงมา และอยู่สูงกว่ามอนสเตอร์อย่างน้อย 10 px จะทำลายมอนสเตอร์ เด้งตัวขึ้น และได้คะแนน

📍 ที่ไหนใน C2: game sheet → กลุ่ม "เหยียบมอน / โดนชนลดหัวใจ"

3

โดนชนด้านข้าง (ถ้าไม่ใช่การเหยียบ)

Else (ต่อจากเงื่อนไขการชนด้านบน)
player → Is flashing (Inverted)
System → Subtract 1 from พลังชีวิต
player.Platform → Set vector X to choose(−450, 450)
player.Platform → Set vector Y to −350
player → Flash (On 0.1, Off 0.1, Duration 3.0)

ถ้าไม่ได้เหยียบและไม่ได้กระพริบอยู่ จะหักพลังชีวิต กระเด็นสุ่มซ้ายขวา และกระพริบอมตะ 3 วินาที

📍 ที่ไหนใน C2: game sheet → กลุ่ม "เหยียบมอน / โดนชนลดหัวใจ"

4

โดนกระสุน ใช้กฎเดียวกัน

player → On collision with enemy_bullet
player → Is flashing (Inverted)
Subtract 1 from พลังชีวิต • Flash for 3.0 seconds
player → Set vector X to choose(−450, 450)
player → Set vector Y to −350 • enemy_bullet → Destroy

ถ้าไม่ได้กระพริบอยู่ จะโดนดาเมจ กระเด็น และทำลายกระสุนทิ้ง

📍 ที่ไหนใน C2: game sheet → กลุ่ม "เหยียบมอน / โดนชนลดหัวใจ"

5

พลังชีวิตหมดแล้ว Game Over

System → Compare พลังชีวิต ≤ 0
System → Trigger once
System → Compare กำลังจบด่าน = 0
player → Set Platform enabled: Disabled
Wait 1 second → Go to layout "Game Over"

เช็ค กำลังจบด่าน=0 เพื่อไม่ให้ทำงานซ้ำถ้าผู้เล่นบังเอิญเลือดหมดตอนกำลังเดินเข้าเส้นชัย

📍 ที่ไหนใน C2: game sheet → กลุ่ม "ตัวครละครออกจากฉาก"

⚠️ ข้อผิดพลาดที่พบบ่อย

- ใส่เหตุการณ์ Else ผิดที่ (ต้องคลิกขวาที่เงื่อนไขบรรทัดแรกของการชน ไม่ใช่เงื่อนไขย่อย)
- ลืมเช็คว่า player ต้อง Is falling ถึงจะนับเป็นการเหยียบ
- เรียง Action การลดเลือดไว้ใต้ Every tick ทำให้เลือดลดรัวๆ (ต้องใช้คู่กับการเช็ค On collision เท่านั้น)
รายการทดสอบ: เหยียบมอนสเตอร์จากด้านบนจะเด้งขึ้นและมอนหายไป • โดนชนด้านข้างจะกระเด็นและกระพริบ 3 วินาที • ระหว่างกระพริบไม่เสียเลือด • หัวใจ 0 เข้า Game Over ครั้งเดียว
