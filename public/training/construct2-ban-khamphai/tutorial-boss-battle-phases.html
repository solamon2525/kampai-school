บทที่ 14 • ระบบบอส

การสร้างบอสประจำด่านและท่าโจมตี

หลอดเลือดบอส (Boss HP Bar) → สลับแพตเทิร์นการโจมตี 3 เฟส → เอฟเฟกต์กระเด็น/กระพริบ → สร้างประตูเมื่อชนะ

👹 BOSS HP: 20 / 30 (Phase 2)
👹
วาง Sprite บอส→สร้างตัวแปร HP→ทำหลอด HP→สลับเฟสการโจมตี→เอฟเฟกต์ชนะ
1

สร้าง Sprite บอส และตัวแปร

วาง Sprite บอสขนาดใหญ่ชื่อ boss

Instance Variable:
• บอสHP (Number) = 30
• เฟส (Number) = 1
2

ทำหลอดพลังชีวิต (HP Bar)

สร้าง Sprite หลอดเลือดสีแดงชื่อ boss_hp_bar บน Layer HUD

System → Every tick
boss_hp_bar → Set width to
max(0, (boss.บอสHP / 30) × 300)

ความกว้างหลอดจะลดลงตามสัดส่วน HP ที่เหลืออย่างแม่นยำ

3

เฟส 1 (HP 21–30): เดินยิงช้าๆ

ยิงกระสุนเดี่ยวหาผู้เล่นทุก 3 วินาที

boss.บอสHP > 20
boss → Set เฟส to 1
Every 3.0 seconds → Create boss_bullet
4

เฟส 2 (HP 11–20): ยิงกระจาย 3 ทิศ

เพิ่มความเร็วและยิงเป็นพัด 3 ทิศทาง

boss.บอสHP ในช่วง 11..20
boss → Set เฟส to 2
Every 2.0 seconds → Create 3 boss_bullets
Angles: -15°, 0°, +15°
5

เฟส 3 (HP 1–10): โหมดคุ้มคลั่ง (Rage Mode)

บอสเปลี่ยนเป็นสีแดง กระโดดทุ่มตัว และปล่อยลูกน้องมอนสเตอร์

boss.บอสHP ≤ 10 → Set เฟส to 3
boss → Set color tint to Red (255, 100, 100)
Every 4.0 seconds → Spawn minion_monster
6

เอฟเฟกต์เมื่อชนะบอส

boss.บอสHP ≤ 0
System → Trigger once
Audio → Play "explosion_big"
boss → Spawn explosion_effect
boss → Destroy
Create door at boss.X, boss.Y
รายการทดสอบ: หลอด HP บอสลดลงสมูท • HP ลดถึง 20 สลับเป็นเฟส 2 (ยิง 3 ทิศ) • HP ลดถึง 10 บอสเปลี่ยนสีแดง • บอส HP 0 ระเบิดหายไปแล้วสร้างประตูชนะ
