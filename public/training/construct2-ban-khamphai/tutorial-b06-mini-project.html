บทที่ B6 • พื้นฐาน Construct 2

Mini Project: เดินบนพื้นเก็บดาว

สรุปการเรียนรู้: Layout • Layer • Sprite • Behavior • Event

1

สร้าง Layout และ Layers

สร้างโปรเจกต์ใหม่ขนาด Window Size: 1280×720. สร้าง 3 Layers เรียงลำดับจากล่างขึ้นบน: bg, game, HUD. วาง TiledBackground เป็นพื้นบน Layer game และใส่ Behavior: Solid.

📍 ที่ไหนใน C2: File → New → Empty project

2

วาง Player + Behaviors

สร้าง Sprite player บน Layer game. ใส่ Behavior: Platform (Jump strength: 650, Gravity: 1500, Max jumps: 2) และ Scroll To. สร้าง Animation: walk, Stand.

📍 ที่ไหนใน C2: Layer game → Insert → Sprite

3

วาง Sprite ดาว

สร้าง Sprite star นำไปวางบนเกาะหรือพื้นที่ต่างๆ 1-3 ดวง. ใช้ Animation หรือเปลี่ยนภาพเป็นดาวหรือเหรียญ.

📍 ที่ไหนใน C2: Layer game → Insert → Sprite ใหม่

4

Event Sheet: เดิน + เก็บดาว

สร้าง Group แยกการทำงานเพื่อง่ายต่อการอ่าน:

Group: เดิน+กระโดด Keyboard → On Left arrow pressed → player → Set mirrored / Set animation to "walk" Keyboard → On Right arrow pressed → player → Set not mirrored / Set animation to "walk" Keyboard → On Left arrow released (หรือตรวจสอบไม่กด) → player → Set animation to "Stand" Group: เก็บของ player → On collision with star → star → Destroy → System → Add 10 to คะแนน → Text → Set text to "คะแนน : " & คะแนน

📍 ที่ไหนใน C2: Event sheet → Add event

5

เช็กลิสต์จบหลักสูตร Beginner

✅ เปิด C2 และใช้งาน Layout/Layer ได้
✅ สร้าง Sprite + Animation เป็น
✅ รู้จัก Condition และ Action
✅ ใส่ Behavior พื้นฐานได้ (Solid, Platform, Scroll To)
✅ สร้างตัวแปรและใช้งานได้
✅ สามารถทำฉากเดียวให้เล่นได้!

ถ้าทำครบหมด → พร้อมเข้า Core Track แล้ว!

6

⚠️ ก่อนเข้า Core Track

เก็บโปรเจกต์ Mini นี้ไว้เป็นตัวอย่างให้ตัวเองดู. ใน Core Track เราจะใช้ไฟล์ master_v32.capx ที่เป็นเกม Red Hood Adventure จริง.
ห้ามแก้ไฟล์ master_v32.capx ล่วงหน้า จนกว่า Mini Project นี้จะสามารถรันและเล่นได้สมบูรณ์!
