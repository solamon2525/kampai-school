บทที่ 15 • สรุปผลการเรียนรู้

ฉากสรุปผลและเกียรติบัตรในเกม

คำนวณดาวประเมิน (1–3 ดาว) → สรุปคะแนนรวมและชื่อนักเรียน → แสดงเกียรติบัตรจำลองในเกม

🏆 ประกาศนียบัตรผ่านการทดสอบคณิตศาสตร์ 🏆
ขอมอบให้แก่: เด็กชาย / เด็กหญิง [ชื่อผู้เล่น]
⭐ ⭐ ⭐
คะแนนรวมสุทธิ: 4,850 คะแนน
ผ่านด่านทั้งหมด→คำนวณดาว→แสดงเกียรติบัตร→แสดงชื่อ/คะแนน→ปุ่มเล่นใหม่
1

คำนวณจำนวนดาวประเมิน

สร้าง Global Variable ดาวประเมิน (Number) = 1

หัวใจ = 5 AND เวลาคงเหลือ > 60
Set ดาวประเมิน to 3
หัวใจ ในช่วง 3..4
Set ดาวประเมิน to 2
2

แสดงดาวประเมินบนหน้าจอ

สร้าง Sprite รูปดาว 3 ดวง บน Layout "Victory"

ดาวประเมิน = 3 → แสดงดาวครบ 3 ดวง
ดาวประเมิน = 2 → แสดงดาว 2 ดวง (ดวงที่ 3 เป็นดาวเทา)
ดาวประเมิน = 1 → แสดงดาว 1 ดวง
3

ดึงชื่อและคะแนนมาจัดวาง

นำค่าจาก Global Variables มาใส่ใน Text Objects

name_label → Set text to "ขอมอบให้แก่: " & ชื่อผู้เล่น
score_label → Set text to "คะแนนรวม: " & คะแนนรวม
4

ปุ่มเล่นใหม่อีกครั้ง

ปุ่ม Replay สำหรับเริ่มเล่นตั้งแต่ด่าน 1 ใหม่

On Button "เล่นอีกครั้ง" Clicked
Set หัวใจ to 5 • Set คะแนนรวม to 0
System → Go to layout "Level 1"
5

การเปิดพลุกระดาษฉลองชัยชนะ (Confetti FX)

On start of layout "Victory":
Audio → Play "fanfare_win"
System → Repeat 20 times: Spawn confetti_particle at random positions

สร้างบรรยากาศแห่งความสำเร็จและภาคภูมิใจให้แก่นักเรียนเมื่อจบเกม

6

ปุ่มกลับหน้าเลือกด่านและเมนู

On Button "เมนูหลัก" Clicked:
System → Go to layout "Title Menu"
รายการทดสอบ: คำนวณดาว 1–3 ดาวถูกต้องตามเกณฑ์ • แสดงชื่อและคะแนนตรงกับที่กรอกไว้ • เสียง Fanfare เล่นครั้งเดียว • ปุ่ม Replay รีเซ็ตค่าหัวใจและคะแนนถูกต้อง
