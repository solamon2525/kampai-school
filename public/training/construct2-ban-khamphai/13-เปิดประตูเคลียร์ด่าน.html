เปิดประตูและเคลียร์ด่าน

distance≤220 · กำลังจบด่าน · ผ่านด่านN · transition

เป้าหมายบทนี้: เมื่อตอบครบแล้วเข้าใกล้ประตู ให้เคลียร์ด่านครั้งเดียว ล็อกด่าน และกลับ select
ครบโจทย์→เข้าใกล้ door→คะแนน+เวลา→ล็อกด่าน→select
1

เงื่อนไขเปิดประตู (อ่านจากบนลงล่าง)

กลุ่ม “6 เปิดประตูเมื่อทำครบ”
distance(player.X, player.Y, door.X, door.Y) ≤ 220
ข้อปัจจุบัน > จำนวนข้อทั้งหมด
กำลังจบด่าน = 0
Trigger once while true

ใช้ระยะแทน On collision เพราะขอบรูปประตูอาจไม่ตรงภาพ

2

Actions ตอนเคลียร์

กำลังจบด่าน = 1
คะแนน += เวลา
Stop all audio · Play "Area Clear"
Platform → Set ignoring input
Set animation walk · vector X = 220 (เดินเข้าประตู)
3

ล็อกด่านตาม LayoutName

game → ผ่านด่าน1 = 1
game2 → ผ่านด่าน2 = 1
game3 → ผ่านด่าน3 = 1

select sheet จะปิดปุ่มด่านที่ผ่านแล้ว

4

transition กลับ select

โชว์ transition_cover (จอดำ/เฟด)
Wait สั้นๆ → Go to layout "select"
อย่าลืมให้ระบบรีเซ็ต กำลังจบด่าน ตอนเริ่มด่านใหม่
5

ทดสอบเส้นทางเคลียร์

  1. Cheat ชั่วคราว: ตั้งข้อปัจจุบัน = 6 แล้วเดินใกล้ประตู
  2. ได้คะแนนเพิ่มเท่าเวลา
  3. กลับ select · ด่านนั้นล็อก
ทดสอบก่อนไปบทถัดไป: ครบ 5 ข้อแล้วเข้าใกล้ประตูได้ · ได้โบนัสเวลา · ด่านล็อก · กลับ select · ไม่เคลียร์ซ้ำ
