บทที่ A3 • Construct 2 ขั้นสูง

Functions — ลดโค้ดซ้ำ

เตรียม Function Object • สร้างฟังก์ชัน • การส่ง Parameter

1

เตรียม Function Object

ฟังก์ชันใน Construct 2 ต้องการ Object เสริมเพื่อทำงาน ตรวจสอบว่าโปรเจกต์มี Object ชนิด Function แล้วหรือยัง หากยังไม่มีให้เพิ่มเข้ามาก่อน

📍 ที่ไหนใน C2: ดับเบิลคลิกพื้นที่ว่างใน Layout → Insert object → ค้นหาคำว่า Function (ในกลุ่ม Data & Storage)
2

สร้างและเรียกใช้

สร้างนิยามของฟังก์ชันและกำหนด Action ภายใน:

Function → On function "ApplyDamage"
System → Subtract 1 from พลังชีวิต
player → Flash 3s
Audio → Play "hurt"

เมื่อต้องการให้เหตุการณ์เหล่านี้ทำงาน ให้เรียกฟังก์ชันนี้:

Function → Call "ApplyDamage"
📍 ที่ไหนใน C2: Event sheet → Add event → Function
3

ฟังก์ชันแนะนำสำหรับ v32

หากเรามีจุดที่โค้ดซ้ำกันหลายแห่ง ให้สร้างฟังก์ชันขึ้นมาแทน เช่น:

  • ApplyDamage: ลดพลังชีวิต + Flash ตัวละคร + เล่นเสียงเจ็บ (เรียกเมื่อชนมอนสเตอร์, โดนกระสุน, หรือตอบคำถามผิด)
  • SpawnQuestion: สร้างโจทย์ข้อใหม่ขึ้นมาสุ่ม (เรียกเมื่อเริ่มด่าน หรือเมื่อผู้เล่นตอบข้อที่แล้วเสร็จ)
  • SaveTop5: ตรวจสอบและบันทึกคะแนนแทรกลงในตาราง Top 5
  • ClearStage: เคลียร์ค่าตัวแปรเมื่อจบด่าน + ทำ Transition หน้าจอ
📍 ที่ไหนใน C2: เลื่อนดูใน Event Sheet หา Action ที่เหมือนกันหลายจุด แล้วทำการแยกออกมาใส่ Function
4

ส่ง Parameter

ฟังก์ชันสามารถรับค่า (Parameter) มาประมวลผลได้ ทำให้ยืดหยุ่นมากขึ้น เช่น:

Function → On function "ApplyDamage"
System → Subtract Function.Param(0) from พลังชีวิต

เวลาเรา Call ฟังก์ชัน เราจะส่งค่า Parameter ไปด้วย เช่น ชนมอนสเตอร์ธรรมดาส่ง 1 ถ้าชนบอสส่ง 2

📍 ที่ไหนใน C2: Action ของ Function → Call function → มีช่องให้ Add parameter ด้านล่างของชื่อฟังก์ชัน
5

⚠️ ข้อผิดพลาดที่พบบ่อย

  • พิมพ์ชื่อ function ผิดตอน Call (Construct 2 จะไม่แจ้ง error แต่ฟังก์ชันจะไม่ทำงาน)
  • ใช้ Action Wait ภายในเนื้อหาของ Function (อาจทำให้ Timing และ Flow ของฟังก์ชันผิดพลาดได้)
  • ลืม Include หรือ Insert Function object ลงในโปรเจกต์แต่แรก
✅ รายการทดสอบ: มี Function อย่างน้อย 1 ตัวในโปรเจกต์ • มีการเรียกใช้ (Call) จาก 2 จุดขึ้นไปในเกม • สังเกตเห็นได้ชัดเจนว่าช่วยลดจำนวน Event ที่ซ้ำซ้อนกัน
