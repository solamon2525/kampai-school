Platform→ปุ่มควบคุม→หันซ้าย–ขวา→เลือก Animation
1

ใส่ Platform behavior

เลือก Sprite player → Behaviors → Add new behavior

เพิ่ม Platform
Default controls: Yes
Max speed: 330
Acceleration: 1500
Deceleration: 1500

ใช้ปุ่มลูกศรซ้าย–ขวาและปุ่ม Shift กระโดดได้ทันที

2

ตั้งค่าการกระโดด

ตั้งค่าใน Properties ของ Platform behavior

Jump strength: 650
Gravity: 1500
Max fall speed: 1000
Double jump: Enabled

ถ้า Construct 2 รุ่นที่ใช้ไม่มี Double jump ให้ใช้ตัวแปรนับจำนวนกระโดดแทน

3

หันหน้าไปทางขวา

ตรวจความเร็วแนวนอน ถ้ามากกว่า 0 ให้หันขวา

player.Platform.VectorX > 0
player → Set mirrored: Not mirrored

ภาพต้นฉบับของ player ควรวาดให้หันขวา เพื่อให้จำง่าย

4

หันหน้าไปทางซ้าย

ถ้าความเร็วน้อยกว่า 0 ให้กลับภาพในแนวนอน

player.Platform.VectorX < 0
player → Set mirrored: Mirrored

ไม่ใช้ Set angle 180° เพราะจะทำให้ตัวละครกลับหัว

5

สร้าง Animation 4 ชุด

Idle = ยืนนิ่ง • Loop: Yes • Speed: 6
Run = วิ่ง • Loop: Yes • Speed: 12
Jump = กำลังกระโดดขึ้น • Loop: No
Fall = กำลังตกลง • Loop: Yes หรือใช้ 1 เฟรม

ตั้งชื่อให้ตรงตัวพิมพ์ทุกตัว เพราะ Construct 2 แยกชื่อ Animation ตามข้อความที่กรอก

6

เลือก Animation ตามลำดับความสำคัญ

player.Platform → Is falling → Set animation "Fall"
Else + Is jumping → Set animation "Jump"
Else + Is moving → Set animation "Run"
Else → Set animation "Idle"

เรียง Fall/Jump ก่อน Run/Idle เพื่อไม่ให้แอนิเมชันวิ่งแย่งทำงานขณะอยู่กลางอากาศ

7

ป้องกัน Animation เริ่มใหม่ทุกเฟรม

ใน Action Set animation เลือก Play from: Current frame หากมีตัวเลือก หรือเพิ่มเงื่อนไขก่อนเปลี่ยน:

player.AnimationName ≠ "Run"
player → Set animation "Run"

ช่วยให้เฟรมวิ่งเล่นต่อเนื่อง ไม่ย้อนกลับเฟรมแรกตลอดเวลา

รายการทดสอบ: ปล่อยปุ่มแล้วหยุด • เดินซ้าย/ขวาหันถูกทิศ • กระโดดได้ 2 ครั้ง • Jump เปลี่ยนเป็น Fall ที่จุดสูงสุด • ลงพื้นกลับ Idle/Run • ตัวละครไม่กลับหัวและ Animation ไม่กระพริบ
