บทที่ B2 • พื้นฐาน Construct 2

Sprite, Animation และ Layer

การสร้างตัวละคร • อนิเมชั่น • การจัดชั้น Layer • การตั้งค่า Collision

1 สร้าง Sprite

ดับเบิลคลิกพื้นว่างใน Layout → Insert new object → Sprite. จากนั้นทำการ Import รูป PNG (ต้องมีพื้นหลังโปร่งใส) แล้วตั้งชื่อ เช่น player.

📍 ที่ไหนใน C2: Layout → ดับเบิลคลิกพื้นว่าง → Insert → Sprite

2 สร้าง Animation หลายชุด

ดับเบิลคลิก Sprite → Animations panel ด้านซ้าย. คลิกขวา → Add animation → ตั้งชื่อเช่น walk, Stand, jump. Import เฟรมภาพ (ใช้ Strip Import ได้). ตั้งค่า Speed ประมาณ 8–12.

📍 ที่ไหนใน C2: ดับเบิลคลิก Sprite → Animations panel

3 จัด Layers 3 ชั้น

สร้าง 3 Layer พื้นฐาน:
- bg (ฉากหลัง, ล่างสุด)
- game (ตัวละคร/วัตถุ, ชั้นกลาง)
- HUD (แสดงผล UI เช่น หลอดเลือด, บนสุด)
* HUD ต้องคลิกที่ Layer แล้วตั้งค่า Parallax ใน Properties เป็น 0,0 เพื่อให้อยู่กับที่ ไม่เลื่อนตามฉาก

📍 ที่ไหนใน C2: แถบ Layers (มักอยู่ทางขวาล่างของหน้าจอ)

4 แก้ Collision Polygon

ดับเบิลคลิก Sprite → คลิกไอคอน Collision polygon (ด้านซ้าย) → ลากจุดให้พอดีกับรูปร่าง. ถ้ากรอบ Collision ใหญ่กว่ารูป จะทำให้ตัวละครชนกำแพงที่มองไม่เห็นก่อนที่รูปจะแตะกำแพงจริงๆ

📍 ที่ไหนใน C2: Image editor (ดับเบิลคลิก Sprite) → เครื่องมือ Set collision polygon

⚠️ ข้อผิดพลาดที่พบบ่อย

  • ชื่อ Animation: โปรแกรมแยกตัวพิมพ์เล็ก/พิมพ์ใหญ่ (Case-sensitive) เช่น walk ไม่เหมือนกับ Walk ต้องเรียกให้ถูกต้องเวลาเขียนโค้ด
  • ลืมตั้ง Parallax ที่ HUD Layer: ทำให้เวลาเดิน UI จะหลุดออกนอกจอ
  • วาง object ผิด Layer: ฉากไปบังตัวละคร หรือตัวละครไปบัง UI
