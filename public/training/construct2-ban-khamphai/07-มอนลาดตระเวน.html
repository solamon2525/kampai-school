บทที่ 7 · เฟส C · มอน · ทำตามทีละขั้น

มอนลาดตระเวนและหันหน้า

eminy · Sine · จำ X ก่อนหน้า · Mirrored

เป้าหมายบทนี้: ให้มอนเดินซ้าย–ขวาในเขต และหันหน้าตามทิศที่เดิน
วาง eminy→Sine→ตัวแปร X→Event หันหน้า
1

วางมอน eminy

Layout → Layer game
  1. วาง Sprite eminy บนพื้น
  2. Behaviors → Add Sine
  3. Sine: Movement = Horizontal · ตั้ง Period/Magnitude ตามต้องการ
Instance variable: ตำแหน่งXก่อนหน้า (Number)
2

Event หันหน้า

กลุ่ม “มอนสเตอร์หันหน้าตามทิศเดิน”
Every tick:
ถ้า eminy.X < ตำแหน่งXก่อนหน้า → กำลังเดินซ้าย → Set mirrored
ถ้า X มากกว่า → เดินขวา → Set not mirrored
แล้ว Set ตำแหน่งXก่อนหน้า = eminy.X
3

ด่าน 2–3 สุ่มตำแหน่ง

กลุ่ม สุ่มมอนสเตอร์และประตู (เฉพาะด่าน 2-3)
สุ่มเฉพาะพิกัดที่ตรวจแล้วว่าผู้เล่นเดิน/กระโดดถึง

อย่าสุ่มมอนบนหลุมหรือสูงเกินกระโดด

4

ทดสอบ

  1. มอนเดินไปกลับ
  2. หน้าหันตามทิศ (ไม่กลับหัว)
  3. ไม่ติดกำแพงแปลกๆ
ทดสอบก่อนไปบทถัดไป: มอนเดินซ้ายขวา · หน้าตรงทิศ · ด่าน 2–3 สุ่มในช่วงที่ถึงได้
