บทที่ A2 • Construct 2 ขั้นสูง

Object Families — จัดกลุ่มมอน/กระสุน

ลด Event ซ้ำซ้อน • บริหารจัดการง่าย • ควบคุม Behavior พร้อมกัน

1

เมื่อไหร่ควรใช้ Family

เมื่อเรามี Object หลายตัวที่ใช้ Event เหมือนกัน เช่น มีมอนสเตอร์ 3 ชนิด ที่เมื่อ Player เดินไปชนแล้วเสียพลังชีวิตเหมือนกันทุกตัว การใช้ Family จะทำให้เราไม่ต้องเขียน Event แยกกันซ้ำๆ 3 ชุด

📍 ที่ไหนใน C2: แนวคิดก่อนลงมือ — สังเกตดูว่ามี Event ที่ทำงานคล้ายกันกับหลาย Object หรือไม่
2

สร้าง Family

สร้าง Family Enemies โดยรวม eminy และมอนสเตอร์ตัวใหม่เข้าด้วยกัน และสร้าง Bullets ที่รวม emon_bullet กับกระสุนชนิดใหม่

📍 ที่ไหนใน C2: Project bar → โฟลเดอร์ Families → คลิกขวา Add family → ตั้งชื่อและเลือกสมาชิก
3

Event กับ Family

เมื่อเปลี่ยนจาก Object เป็น Family โค้ดจะครอบคลุมสมาชิกทุกตัวทันที:

player → On collision with Enemies
System → Subtract 1 from พลังชีวิต

ระบบเหยียบมอนสเตอร์หรือชนข้างจากบทที่ 5 จะสามารถนำมาใช้ได้ทันทีกับมอนสเตอร์ทุกตัวที่อยู่ใน Family เดียวกัน ในทำนองเดียวกันการเช็คการชนกับกระสุน ก็เช็คจาก player On collision Bullets ได้เลย

📍 ที่ไหนใน C2: Event sheet → ดับเบิลคลิกแก้ไข Event → เปลี่ยน object picker จากชื่อมอนสเตอร์เป็นชื่อ Family
4

ข้อจำกัดที่ต้องรู้

สิ่งสำคัญ: ทุกสมาชิกใน Family ต้องมี Behavior และ Instance variable ที่มีชื่อเหมือนกันทุกประการ

หาก eminy มีตัวแปร ตำแหน่งXก่อนหน้า แต่มอนสเตอร์ตัวใหม่ที่เราเพิ่งเพิ่มไม่มีตัวแปรนี้ Event ที่อ้างอิงตัวแปรดังกล่าวจะเกิด Error ทันที

5

⚠️ ข้อผิดพลาดที่พบบ่อย

  • ลืมเพิ่ม Behavior หรือ Instance variable ให้สมาชิกใหม่ (Construct 2 จะไม่แจ้ง Warning เสมอไป)
  • ตั้งชื่อ Family ซ้ำกับชื่อ Object ในโปรเจกต์
  • ลบ Object ออกจาก Layout แล้ว แต่ลืมเอาออกจาก Family (อาจทำให้เกิดบั๊กใน Event sheet)
✅ รายการทดสอบ: สร้าง Family สำเร็จ • เพิ่มสมาชิกเข้าไปใน Family ได้ถูกต้อง • ทดสอบแล้ว Event การชนกับ Family ทำงานได้ครบทุกตัว • เข้าใจเรื่องข้อจำกัดที่ Behavior และ Variable ต้องตรงกัน
