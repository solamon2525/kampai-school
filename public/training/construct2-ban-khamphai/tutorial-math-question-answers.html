สุ่มโจทย์→คำนวณคำตอบ→สร้างตัวลวง→สลับตำแหน่ง→ให้ผู้เล่นเลือก
1

สร้างตัวแปรโจทย์

เพิ่ม Global variables ใน Event Sheet

ตัวตั้ง • Number • 0
ตัวคูณ • Number • 0
คำตอบถูก • Number • 0
ข้อปัจจุบัน • Number • 1
จำนวนข้อทั้งหมด • Number • 5
2

เตรียมวัตถุคำตอบ

สร้าง Sprite ดาวชื่อ answer_star และ Text ชื่อ answer_text

answer_star → Instance variable
ค่าคำตอบ • Number • 1
ช่องคำตอบ • Number • 0

ตัวเลขควรมีสีเข้ม ขอบขาว ขนาดอย่างน้อย 32 px และอยู่เหนือดาว

3

สุ่มและคำนวณโจทย์

System → On start of layout
Set ข้อปัจจุบัน to 1
Set ตัวตั้ง to int(random(2,13))
Set ตัวคูณ to int(random(2,13))
Set คำตอบถูก to ตัวตั้ง × ตัวคูณ

คำนวณคำตอบจากตัวเลขโจทย์เสมอ ห้ามสุ่มคำตอบถูกแยกเอง

4

แสดงโจทย์บน HUD

สร้าง Text ชื่อ question_text บน Layer HUD

question_text → Set text to
"ข้อ " & ข้อปัจจุบัน & "/5 : " &
ตัวตั้ง & " × " & ตัวคูณ & " = ?"

ใช้สีกรมท่าหรือดำบนกล่องพื้นหลังสีอ่อน เพื่อไม่กลืนกับฉาก

5

สร้างคำตอบหลอก 2 ค่า

เพิ่มตัวแปร หลอก1 และ หลอก2 แล้วคำนวณแบบอ่านง่าย

Set หลอก1 to max(1, คำตอบถูก − int(random(1,6)))
Set หลอก2 to คำตอบถูก + int(random(1,6))
หลอก1 = คำตอบถูก OR หลอก1 = หลอก2 OR หลอก2 = คำตอบถูก → สุ่มใหม่

max(1, …) รับประกันว่าไม่มีคำตอบ 0 หรือติดลบ

6

สุ่มตำแหน่งคำตอบถูก

Set ตำแหน่งคำตอบถูก to int(random(1,4))
ถ้าตำแหน่ง = 1 → ช่อง 1 = คำตอบถูก, ช่อง 2 = หลอก1, ช่อง 3 = หลอก2
ถ้าตำแหน่ง = 2 → ช่อง 1 = หลอก1, ช่อง 2 = คำตอบถูก, ช่อง 3 = หลอก2
ถ้าตำแหน่ง = 3 → ช่อง 1 = หลอก1, ช่อง 2 = หลอก2, ช่อง 3 = คำตอบถูก
7

ผูกตัวเลขกับดาว

ดาวและ Text แต่ละคู่ต้องมี ช่องคำตอบ เลขเดียวกัน

System → Every tick
answer_text.ช่องคำตอบ = answer_star.ช่องคำตอบ
Set position to answer_star.X, answer_star.Y
Set text to answer_star.ค่าคำตอบ
8

ตรวจความถูกต้อง

player → On collision answer_star
ค่าคำตอบ = คำตอบถูก → ถูกต้อง / ไปข้อถัดไป
Else → ผิด / ลดหัวใจ / ลบดาวนั้น

ล็อกการชน 1 วินาทีหลังตอบถูก ป้องกันเพิ่มข้อซ้ำ

รายการทดสอบ: สุ่มอย่างน้อย 30 ชุด • คำตอบถูกตรงกับโจทย์ • ทั้ง 3 ค่าไม่ซ้ำ • ไม่มี 0 • ถูกเพียงหนึ่งช่อง • ตัวเลขมองเห็นชัดและตามดาว • ตอบผิดไม่เพิ่มข้อ
