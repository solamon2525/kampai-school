WebStorage / เซฟความคืบหน้า

จำชื่อ · คะแนน · ผ่านด่าน หลังปิดเบราว์เซอร์

เป้าหมายบทนี้: บันทึกและโหลดข้อมูลสำคัญด้วย WebStorage เพื่อไม่หายเมื่อปิดเกม
Local storage→Set item→On start Check→Load
1

เพิ่ม WebStorage

Insert → WebStorage

ใช้ Local storage (ต่อเครื่อง/เบราว์เซอร์)

2

เซฟตอนสำคัญ

หลังเคลียร์ด่าน / หลังบันทึก Top5 / หลังใส่ชื่อ:
WebStorage → Set local item "playerName" to ชื่อผู้เล่น
Set "pass1" to ผ่านด่าน1 (และ 2, 3)
Set "score1"…"name1" …
3

โหลดตอนเปิดเกม

On start of layout title
WebStorage → Local key "playerName" exists
Set ชื่อผู้เล่น to WebStorage.LocalValue("playerName")

ถ้าไม่มี key → ใช้ค่าเริ่มต้นว่าง/0

4

ข้อจำกัด

ข้อมูลผูกเบราว์เซอร์/เครื่อง · ล้าง cache แล้วหาย
อย่าเก็บข้อมูลลับใน WebStorage
ทดสอบ: ปิดแท็บแล้วเปิดใหม่ ด่านที่ผ่านยังล็อก
ทดสอบก่อนไปบทถัดไป: เซฟชื่อได้ · โหลดผ่านด่านได้หลังรีเฟรช · ไม่พังเมื่อยังไม่เคยเซฟ
