แพ็ก capx / Export HTML5

zip path ใช้ / · UID ไม่ซ้ำ · Preview vs Export

เป้าหมายบทนี้: แพ็กและส่งออกเกมให้เปิดใน Construct 2 และรันบนเว็บได้โดยไม่พัง
Save capx→ตรวจ UID→Export HTML5→ทดสอบเบราว์เซอร์
1

บันทึก .capx

File → Save as
ถ้าแก้จาก extract แล้ว zip กลับเป็น capx:
ใช้ path แบบ forward slash / เท่านั้น
backslash \ → Construct 2 เปิดไม่ได้
2

ตรวจก่อนส่ง

  1. ไม่มี UID ซ้ำระหว่าง Layout ที่ก็อปมา
  2. First layout = title
  3. เสียง/ภาพครบในโปรเจกต์
  4. Preview F5 ผ่าน flow หลัก
3

Export HTML5

File → Export project → HTML5
ได้โฟลเดอร์มี index.html
อัปโหลดทั้งโฟลเดอร์ หรือเปิด local ตามนโยบายเบราว์เซอร์
4

Preview ≠ Export บางจุด

TextBox / Touch / Audio บางเบราว์เซอร์ต่างกัน
ทดสอบ Chrome/Edge หลัง Export จริง
ทดสอบก่อนไปบทถัดไป: เซฟ capx เปิดกลับได้ · รู้กฎ zip path · Export HTML5 แล้วเปิดเล่น flow หลักได้
