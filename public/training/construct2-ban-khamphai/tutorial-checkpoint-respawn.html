บทที่ 3 • ระบบความต่อเนื่องของด่าน

Checkpoint และการเกิดใหม่

แตะธงเพื่อบันทึกจุดปลอดภัย • ตกฉากแล้วกลับมาจุดล่าสุด • ไม่ต้องเริ่มด่านใหม่

จำจุดเริ่ม→แตะธง→บันทึก X/Y→ตกแล้วกลับมา
1

สร้างตัวแปร 3 ตัว

คลิกขวา Event Sheet → Add global variable

จุดเกิดX • Number • 0
จุดเกิดY • Number • 0
กำลังเกิดใหม่ • Number • 0

X/Y จำตำแหน่ง ส่วนตัวแปรสุดท้ายใช้ล็อกไม่ให้คำสั่งเกิดซ้ำ

2

จำจุดเริ่มต้นของด่าน

เมื่อเริ่ม Layout ให้อ่านตำแหน่ง player ที่วางไว้

System → On start of layout
Set จุดเกิดX to player.X
Set จุดเกิดY to player.Y
Set กำลังเกิดใหม่ to 0

ไม่ต้องพิมพ์เลขตำแหน่งเอง เมื่อย้าย player ใน Editor ระบบยังถูกต้อง

3

สร้างวัตถุ Checkpoint

เพิ่ม Sprite รูปธง ตั้งชื่อ checkpoint และเพิ่ม Instance variable

checkpoint → Instance variables
Name: เปิดใช้งานแล้ว
Type: Boolean • Initial: False

ธงแต่ละอันจำสถานะของตัวเองได้ เหมาะกับด่านที่มีหลายจุด

4

แตะธงแล้วบันทึกตำแหน่ง

player → On collision with checkpoint
checkpoint.เปิดใช้งานแล้ว = False
Set จุดเกิดX to checkpoint.X
Set จุดเกิดY to checkpoint.Y − 60

ลบ Y 60 เพื่อให้ player เกิดเหนือธง ไม่เกิดซ้อนกับ Collision ของธง

5

แสดงว่าธงทำงานแล้ว

ต่อจาก Event ชนธง
checkpoint → Set เปิดใช้งานแล้ว to True
checkpoint → Set animation "Active"
Audio → Play "checkpoint" (not looping)

สร้าง Animation Inactive และ Active คนละสี ผู้เล่นจะเข้าใจทันทีว่าบันทึกสำเร็จแล้ว

6

ตกฉากแล้วกลับ Checkpoint

player.Y > LayoutHeight + 200
กำลังเกิดใหม่ = 0
Set กำลังเกิดใหม่ to 1
Subtract 1 from หัวใจ
player → Set position to (จุดเกิดX, จุดเกิดY)
player.Platform → Set vector Y to 0

ล้างความเร็วแนวตั้ง เพื่อไม่ให้ player ย้ายกลับแล้วตกต่อด้วยความเร็วเดิม

7

ปลดล็อกหลังเกิดใหม่

หลัง Action ย้ายตำแหน่ง
Wait 0.5 seconds
Set กำลังเกิดใหม่ to 0

ระหว่าง 0.5 วินาที อาจทำให้ player กระพริบและปิด Collision กับมอนสเตอร์ชั่วคราว เพื่อไม่ให้เกิดแล้วโดนโจมตีทันที

รายการทดสอบ: เริ่มด่านแล้วตกก่อนแตะธงต้องกลับจุดเริ่ม • แตะธงแล้วตกต้องกลับธงล่าสุด • ลดหัวใจเพียง 1 • ความเร็วตกถูกล้าง • ธงเปลี่ยนภาพและเสียงเล่นครั้งเดียว
