บทที่ 13 • บันทึกข้อมูล

ระบบบันทึกข้อมูลผู้เล่นลงเครื่อง

แทรก LocalStorage Object → บันทึกชื่อ/ด่าน/คะแนนสูงสุด → อ่านค่ากลับเมื่อเปิดเกม → จำสถานะถาวร

💾 LocalStorage Key: "high_score" ➔ 3,450
🔓 LocalStorage Key: "unlocked_level" ➔ 3
เพิ่ม LocalStorage→บันทึกค่าด้วย Set Item→อ่านค่าเมื่อเริ่มเกม→อัปเดตตัวแปร→แสดงผล
1

ใช้ WebStorage Object

เพิ่ม Plugin WebStorage แทน LocalStorage

WebStorage มีความเสถียรมากกว่าในบางเบราว์เซอร์เก่า

📍 ที่ไหนใน C2: Insert → WebStorage

2

บันทึกข้อมูลเฉพาะที่จำเป็น

ใช้ Set local value บันทึก Key

WebStorage → Set local value
Keys: playerName, pass1, pass2, pass3, score1-5, name1-5

📍 ที่ไหนใน C2: Event Sheets (เมื่อมีการเปลี่ยนแปลงข้อมูล)

3

ตรวจสอบก่อนโหลดข้อมูล

หน้า Title Start ต้องเช็คว่ามี Key หรือไม่

WebStorage → Local key "playerName" exists
Set ชื่อผู้เล่น to WebStorage.LocalValue("playerName")

📍 ที่ไหนใน C2: title sheet

4

กำหนดค่าเริ่มต้นถ้าไม่มี Key

ถ้าเป็นผู้เล่นใหม่

System → Else (ไม่มี Key)
Set ชื่อผู้เล่น to ""
Set score1 to 0

📍 ที่ไหนใน C2: title sheet

5

⚠️ ข้อผิดพลาดที่พบบ่อย

ข้อมูลเซฟหายเมื่อย้ายเครื่อง หรือล้าง Cache

ข้อควรระวัง: WebStorage จะผูกติดกับเบราว์เซอร์และอุปกรณ์นั้นๆ
การแก้ปัญหา: แนะนำผู้เล่นไม่ให้ Clear Cache หรือใช้ Database ออนไลน์แทนหากจำเป็น

📍 ที่ไหนใน C2: ทั่วไป

รายการทดสอบ: ใช้ WebStorage Object • เซฟ Key (playerName, pass1-3, score1-5, name1-5) • เช็ค Key Exists ก่อนโหลด (On start) • ค่าเป็น Default 0/ว่าง หากไม่มีเซฟ
Construct 2 สำหรับผู้เริ่มต้น • Local Storage Persistenceงานถัดไป: การสร้างบอสประจำด่านและท่าโจมตี
