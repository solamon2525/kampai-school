ชื่อเมนูและ Script name สกัดจากไฟล์ edittime.js ของ Construct 2 R280 ที่ติดตั้งในเครื่อง แล้วเทียบกับสำเนาออนไลน์ คำอธิบายภาษาไทยเป็นข้อความเพื่อการสอน ไม่ใช่คำแปลทางการ
- [Common object features](https://www.construct.net/en/construct-2/manuals/construct-2/project-primitives/objects/common-features)

## ระบบภาษาไทย

คำแปลไทยครอบคลุม 524/524 คำสั่ง ใช้พจนานุกรมศัพท์ Construct 2 และตรวจแก้ศัพท์เทคนิคเพิ่มเติม 90 รายการ ชื่อภาษาอังกฤษยังแสดงควบคู่เสมอเพราะเป็นชื่อเมนูจริงในโปรแกรม คำแปลนี้จัดทำเพื่อการสอน ไม่ใช่คำแปลทางการจาก Scirra/Construct.
