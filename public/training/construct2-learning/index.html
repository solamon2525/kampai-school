🧯 ศูนย์แก้ปัญหาสำหรับมือใหม่

คลิกอาการที่พบ แล้วตรวจตามลำดับก่อนแก้ Event อื่น

Player ตกทะลุพื้น
ตรวจ: Ground ต้องมี Solid และ Player ต้องมี Platform จากนั้นเปิด Image editor ตรวจ Collision polygon ของทั้งสอง Object
กดซ้าย–ขวาแล้วไม่เดิน
ตรวจ: มี Keyboard Object, Platform Default controls = No และใช้ Key is down → Simulate Left/Right
กด Space แล้วไม่กระโดด
Event ที่ถูก: Keyboard → On Space pressed → Player.Platform → Simulate control Jump และ Player ต้องยืนบน Solid
กระโดดซ้ำกลางอากาศ
แก้: ใช้ On key pressed ไม่ใช้ Key is down และเพิ่มเงื่อนไข Player.Platform Is on floor หากยังเกิดซ้ำ
Animation กระพริบหรือเริ่มใหม่ตลอด
แก้: Set animation โดย From beginning = No และจัด Event Jump/Fall ไว้เหนือ Idle/Run
HP ลดจาก 3 เหลือ 0 ทันที
แก้: ตรวจ Player.IsHurt = False ก่อนลด HP จากนั้นตั้ง True และคืน False เมื่อ Flash ended
มอนสเตอร์ไม่เดินหรือไม่กลับทิศ
ตรวจ: Enemy มี Platform, Default controls = No, Direction = 1 และมี Simulate Left/Right ตาม Direction
เวลาเดินเร็วเกินไป
แก้: ใช้ System → Every 1.0 seconds → Subtract 1 from TimeLeft ห้ามลด 1 ใน Every tick
เก็บดาวแล้วดาวทุกดวงหาย
แก้: วาง Star Destroy ใน Event On collision เดียวกัน เพื่อให้ Construct เลือกเฉพาะ Instance ที่ชน
Retry แล้วเกมยังหยุด
แก้: ก่อน Restart layout ให้ System → Set time scale = 1 แล้วรีเซ็ต TimeLeft, HP และ Score
