# Worksheet preference profile

This file contains only user-approved defaults. Repository contracts remain authoritative.

## Approved defaults

No historical candidate is approved automatically. Add a rule here only after explicit approval recorded in `preference-evidence.md`.

- For two-column calculation worksheets with at least three written scaffold steps per problem, start at no more than eight questions per page. Use ten only when HTTP browser and 100% A4 evidence confirm readable type and genuinely writable slots. This does not limit short fluency worksheets.

## Working design baseline

Use these as review prompts, not learned mandates:

- Allocate space from the actual handwriting or construction steps instead of forcing a generic question count.
- Preserve authentic paper methods: place-value alignment, long-division boards, diagrams, tables, labels, and reasoning lines must match the assessed process.
- Balance useful density with writable space. Avoid cramped work and large dead regions; never use clipping to make a page fit.
- Prefer meaningful variety, canonical uniqueness, and grade-appropriate values over superficial randomization.
- Use large visual cases when reading or drawing the visual is the skill; use compact cases only when the scaffold remains legible and writable.
- Treat screen preview and 100% A4 print as two views of the same artifact and verify both.

## Review dimensions

Compare writing-space adequacy, scaffold authenticity, alignment, mathematical visual accuracy, density, dead space, hierarchy, answer-reveal stability, grayscale readability, and all-page A4 fit.
