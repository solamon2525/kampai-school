# Teaching media preference profile

This file contains only user-approved defaults. Repository contracts remain authoritative.

## Approved defaults

No historical candidate is approved automatically. Add a rule here only after explicit approval recorded in `preference-evidence.md`.

## Working design baseline

Use these as review prompts, not learned mandates:

- Start from Learn → Demonstrate → Guided Practice → Short Check and make the current phase obvious.
- Make demonstrations explain the learning process, not merely decorate facts.
- Keep practice short and instructional; do not introduce scoring, lives, leaderboard, or race pressure unless explicitly building a game.
- Provide equivalent keyboard and touch paths, visible focus, reduced-motion behavior, and feedback that does not rely on sound alone.
- Keep the main explanation and controls usable at phone, tablet, and classroom-projector sizes.
- For paired worksheets, keep terminology, representation, grade, indicator, and progression consistent without duplicating the same experience.

## Review dimensions

Compare instructional sequence, explanation clarity, interaction affordance, feedback, responsive hierarchy, control reachability, motion accessibility, projector readability, and continuity with the paired worksheet.
