# Design Document: ระบบฝึกอ่านคำยากและคำราชาศัพท์ (Thai Reading Studio Theater)

- **Date:** 2026-11-11
- **Status:** Proposed (Awaiting User Approval)
- **Author:** Antigravity AI & ครูณัฐพงศ์ สิงห์ชมภู
- **Target Application:** `public/games/thai/thai-vocab-hub/` (Thai Vocab Hub)

---

## 1. Intent & The Why (ที่มาและวัตถุประสงค์)

ในการเรียนการสอนภาษาไทยระดับประถมศึกษา (ป.4 – ป.6) นักเรียนมักประสบปัญหาการอ่านออกเสียง **"คำยาก"** (คำหลายพยางค์, คำสมาส-สนธิ, คำแผลง, คำที่มีพยัญชนะไม่ออกเสียง/ตัวการันต์) และ **"คำราชาศัพท์"** ที่มีโครงสร้างเสียงไม่ตรงรูป เช่น:
- *อธิษฐาน* มักอ่านผิดเป็น *อะ-ทิด-สะ-ถาน* หรือสับสนตัวสะกด (คำอ่านที่ถูกต้องคือ `อะ-ทิด-ถาน`)
- *มหัศจรรย์* (คำอ่าน `มะ-หัด-สะ-จัน`) มี 4 พยางค์ และมีตัวการันต์ `ย์`
- *พระเนตร* (คำอ่าน `พะ-เนด`) มักออกเสียงควบกล้ำผิดหรือไม่เข้าใจคำแปลสามัญ (ดวงตา)

หลังจากความสำเร็จของระบบ **"สระแปลงร่างและสระลดรูป" (Thai Vowel Morph Studio v2.8.8)** คุณครูต้องการให้สร้าง **"ระบบฝึกอ่าน"** ในลักษณะเดียวกัน โดยดึงคำศัพท์ที่มีอยู่ในระบบอยู่แล้ว (เน้นคำยาก 100 คำ + คำราชาศัพท์ 100 คำ รวม 200 คำ) มาสร้างเป็นหมวดหมู่ใหม่ และมีโรงละครจอใหญ่ (Projector / Smartboard Screen) แยกชำแหละพยางค์คำอ่านทีละบล็อก (Syllable Breakdown) สังเคราะห์เสียงอ่านออกเสียง และอ่านแจกลูกคำตามจังหวะ เพื่อใช้สอนนักเรียนทั้งชั้นเรียนได้อย่างมีประสิทธิภาพ

## 2. Goals, Non-Goals & Anti-Goals

### 🎯 Goals (เป้าหมายหลัก)
1. **หมวดหมู่ใหม่ในคลังคำศัพท์:** เพิ่มหมวด `📖 ฝึกอ่านคำยากและราชาศัพท์` (`slug: reading-studio`) รวม 200 คำอนุมัติ (100 คำยาก + 100 คำราชาศัพท์) พร้อมแท็บกรองย่อย: *ทั้งหมด (๒๐๐)*, *คำยาก ป.๔-ป.๖ (๑๐๐)*, *คำราชาศัพท์ (๑๐๐)*
2. **โรงละครฝึกอ่านจอใหญ่ (Reading Studio Theater):**
   - ตัวอักษรขนาดใหญ่ `clamp(72px, 14vw, 140px)` บนพื้นฉากขาวสไตล์กระดานไวท์บอร์ด เห็นชัดเจนจากระยะ 3–5 เมตร
   - **แอนิเมชัน 3 จังหวะสะกดอ่าน (Spacebar / ➔ ควบคุม):**
     - **จังหวะที่ 1 (คำตั้งต้น):** แสดงคำศัพท์เต็มคมชัด (เช่น `อธิษฐาน`)
     - **จังหวะที่ 2 (คลี่พยางค์คำอ่าน):** แยกก้อนคำอ่านออกเป็นบล็อกพยางค์ทีละคำ `[ อะ ]` - `[ ทิด ]` - `[ ถาน ]` พร้อมสีถอดรหัสพยางค์สดใสและเน้นตัวสะกดตรงมาตรา
     - **จังหวะที่ 3 (สรุปและบริบท):** แสดงความหมาย คำแปลภาษาทั่วไป (กรณีราชาศัพท์) ชนิดของคำ และตัวอย่างประโยคในชีวิตจริง พร้อมรูปภาพประกอบ (กรณีคำราชาศัพท์)
3. **ระบบเสียง 2 มิติ (Dual Audio Engine):**
   - **Web Audio API:** เสียง Whoosh/Sparkle เมื่อบล็อกพยางค์คลี่คลาย (Zero-dependency, latency ต่ำ)
   - **Web Speech API:** อ่านออกเสียงภาษาไทยทั้งคำ และกดฟังเฉพาะพยางค์ที่ต้องการฝึกซ้ำได้
4. **Card Badge Integration:** มีป้ายกำกับ `📖 ฝึกอ่าน` บนการ์ดคำศัพท์ทั้งในหมวดใหม่ และบนการ์ดในหมวดคำยาก (`difficult`) และหมวดคำราชาศัพท์ (`royal`) คลิกแล้วเปิดโรงละครพร้อมคำนั้นทันที

### 🚫 Non-Goals (สิ่งที่ไม่ทำในรอบนี้)
- ไม่ทำการรู้จำเสียงพูดของนักเรียนผ่านไมโครโฟน (Speech Recognition) เนื่องจากสภาพแวดล้อมห้องเรียนมีเสียงสะท้อนและเสียงรบกวนสูง
- ไม่แก้ไขข้อมูลดิบในหมวดเดิม (`difficult.json` และ `royal.json`) แต่ใช้การรวบรวม (aggregate/curate) เป็นหมวดใหม่ `reading-studio.json`

### ⚠️ Anti-Goals (สิ่งที่ห้ามเกิดขึ้นเด็ดขาด)
- ห้ามมี Layout Overflow ทั้งบนหน้าจอโทรศัพท์ (360×800) และจอเดสก์ท็อป (1280×720) ตาม Classroom-first Product Rules
- ห้ามใช้สีโทน Dark Theme ขัดกับ Light-only design rules ของโรงเรียนบ้านคำไผ่
- ห้ามใช้ ES Modules ในไฟล์เกม (`reading-trainer.js` ต้องเป็น IIFE เผยแพร่ผ่าน `window.ThaiReadingTrainer`)

## 3. Approaches Considered (แนวทางที่พิจารณา)

| แนวทาง | จุดเด่น | จุดด้อย | ผลการตัดสินใจ |
|---|---|---|---|
| **แนวทางที่ 1: โรงละครฝึกอ่านแจกพยางค์ (Reading Studio Theater) + หมวดใหม่** | รองรับจอโปรเจกเตอร์ 16:9, ฟอนต์ใหญ่ชัด 3-5 เมตร, แอนิเมชัน 3 จังหวะเข้าใจง่าย คล้ายสระแปลงร่างที่ครูคุ้นเคย | ต้องสร้างโมดูล Theater และเชื่อมโยง 200 คำ | **เลือกแนวทางนี้** (ตรงกับความต้องการของคุณครูมากที่สุด) |
| **แนวทางที่ 2: โหมดฝึกอ่านคาราโอเกะกะพริบตามเสียง (Bouncing Karaoke)** | มีลูกเล่นหวือหวา | เสี่ยงเรื่อง latency เสียงอ่าน Web Speech กับเวลากะพริบไม่ตรงกันในมือถือบางรุ่น | ไม่เลือก |
| **แนวทางที่ 3: แฟลชการ์ดแยกพยางค์ 2 หน้า (Two-Sided Flashcard)** | ทำง่าย ใช้ UI เดิม | ตัวอักษรเล็ก ไม่เหมาะสำหรับฉายขึ้นจอโปรเจกเตอร์หน้าห้องเรียน | ไม่เลือก |

## 4. Detailed Technical Specification

### 4.1 Data Architecture
- สร้างไฟล์ข้อมูล `public/games/thai/thai-vocab-hub/data/words/reading-studio.json` (200 คำ):
  - 100 คำยากคัดสรร: มีคำอ่านแยกพยางค์ชัดเจน ความหมาย และตัวอย่างประโยค
  - 100 คำราชาศัพท์คัดสรร: มีคำอ่านแยกพยางค์ คำแปลสามัญ ความหมาย และภาพประกอบ/อิโมจิ
  - **Visual Asset Handling:** แสดงรูปภาพเฉพาะคำที่มี `image_url` อยู่แล้วในระบบ (25 คำนำร่อง) ส่วนคำที่ไม่มีรูปจะแสดงผลด้วยอิโมจิประจำคำขนาดใหญ่คู่กับข้อความอย่างสวยงาม (Graceful Fallback) ไม่จำเป็นต้องสร้างภาพใหม่ 75 ภาพ
- เพิ่มหมวดใน `public/games/thai/thai-vocab-hub/data/categories.json`:
  ```json
  {
    "slug": "reading-studio",
    "title": "ฝึกอ่านคำยากและราชาศัพท์",
    "icon": "📖",
    "desc": "ฝึกแจกพยางค์คำอ่านคำยากและคำราชาศัพท์ พร้อมเสียงอ่านและจอใหญ่ฉายห้องเรียน"
  }
  ```
- คอมไพล์รวมเข้า `public/games/thai/thai-vocab-hub/data.js` ผ่านสคริปต์ `pnpm build:vocab`

### 4.2 Module Architecture: `reading-trainer.js`
- ประกาศ `window.ThaiReadingTrainer = { open, close, nextStep, prevStep, selectWord, speakWord, speakSyllable, isReadingWord }`
- **Syllable Breakdown Engine:**
  - สลายคำอ่านด้วย Client-side splitting ผ่านเครื่องหมายยัติภังค์ (`item.reading.split('-')`) ได้ทันที เช่น `"อะ-ทิด-ถาน"` ➔ `["อะ", "ทิด", "ถาน"]`
  - เรนเดอร์เป็นก้อนพยางค์ (Syllable Chips) พร้อมสีลูกกวาดแยกสีพยางค์ละมุนตา สลับสีอัตโนมัติ (ฟ้า ➔ ชมพู ➔ ส้ม ➔ เขียว ➔ ม่วง) ทำให้นักเรียนแยกแยะจังหวะการอ่านได้อย่างรวดเร็ว
  - สามารถคลิกที่ก้อนพยางค์ใด ๆ เพื่อฟังเสียงอ่านเฉพาะพยางค์นั้นซ้ำ ๆ ได้
- **Audio Synthesizer:**
  - `playPop()`: เสียงก้อนพยางค์ดีดตัว
  - `playChime()`: เสียงเฉลยความหมายสำเร็จ
- **State Machine:**
  - `currentStep`: 1 (คำเต็ม) ➔ 2 (ก้อนพยางค์คำอ่าน) ➔ 3 (ความหมายและบริบท)
  - `currentWordIndex`: ดัชนีคำปัจจุบันในรายการ (200 คำ)
  - `activeFilter`: 'all' (ทั้งหมด 200 คำ) | 'difficult' (คำยาก 100 คำ) | 'royal' (คำราชาศัพท์ 100 คำ)
- **Badge Integration & Navigation:**
  - ฟังก์ชัน `isReadingWord(word)` ตรวจสอบการเป็นสมาชิกใน 200 คำคัดสรร
  - แสดงป้าย `📖 ฝึกอ่าน` บนการ์ดคำศัพท์ทั้งในหมวด `reading-studio`, `difficult`, และ `royal`
  - เมื่อคลิกป้ายจากหมวดใดก็ตาม จะเปิดโรงละครและกระโดดไปยังคำนั้นโดยตรง พร้อมตั้งค่า Playlist ไปตามลำดับหมวดที่กำลังเล่น
- **Keyboard Shortcuts:**
  - `Spacebar` / `ArrowRight`: ไปจังหวะถัดไป / คำถัดไป
  - `ArrowLeft`: ถอยหลัง
  - `Escape`: ปิดหน้าต่างโรงละคร

### 4.3 UI & CSS Specifications (`style.css`)
- `.reading-theater-card`: กว้าง 95vw, สูงสุด 880px, สไตล์การ์ดโค้งมน 24px
- `.reading-stage-wrapper`: พื้นหลังสีขาวบริสุทธิ์ `#ffffff` พร้อมเส้นขอบเงาละมุน
- `.reading-word-full`: ฟอนต์ `clamp(72px, 14vw, 140px)` สีดำเข้ม `#0f172a` น้ำหนัก 800
- `.syllable-chips-group`: แถวกล่องพยางค์ ดีดตัวแบบ Pop-in มีสีพื้นละมุนตามลำดับพยางค์ (เช่น ฟ้าคราม, ม่วงพาสเทล, ส้มทอง, เขียวมิ้นต์)
- `.reading-meaning-card`: การ์ดสรุปความหมาย ชนิดคำ และบริบทประโยค
- `.badge-reading-trigger`: ป้ายกำกับบนการ์ดคำศัพท์ สีม่วงพาสเทล `📖 ฝึกอ่าน`

## 5. Verification & Testing Strategy

1. **Static & Verification Tool:**
   - รัน `pnpm build:vocab` เพื่อสร้าง `data.js` และตรวจว่าอนุมัติครบ 200 คำ
   - รัน `pnpm verify:game:all -- public/games/thai/thai-vocab-hub` เพื่อทดสอบ Playwright Smoke Test ครบทั้ง 3 หน้าจอ (Phone 360x800, Tablet 768x1024, Desktop 1280x720)
2. **Build Test:**
   - รัน `pnpm build` (Vite) เพื่อตรวจสอบว่าไม่มี bundling error หรือ syntax issue
3. **Classroom-First Verification:**
   - ตรวจสอบว่าไม่มี text clipping / overflow
   - ตรวจสอบความชัดเจนของตัวหนังสือบนจอ 16:9
   - ตรวจสอบว่าเสียงไม่ออโต้เพลย์ก่อนมี user gesture
