# แบบเพลนหุ่นยนต์เลี้ยงแกะ (สพฐ.) — ถอดจากวิดีโอ

อ้างอิง: [หุ่นยนต์ขาเดินเลี้ยงแกะ — Nampetch Sukkasame](https://youtu.be/P5dfi6EzAWo)

> **หมายเหตุ:** แบบนี้ถอดจากสเปกในคำอธิบายวิดีโอ + กติกา สพฐ. รายการ "หุ่นยนต์เลี้ยงแกะ"  
> ขนาดและตำแหน่งรูยึดอาจต้องปรับ ±1–2 มม. ตามมอเตอร์เกียร์ที่ใช้จริง

## สเปกหลัก (จากวิดีโอ)

| รายการ | ค่า |
|---|---|
| ขนาดรวม | ยาว 29 ซม. × กว้าง 18 ซม. × สูง 11 ซม. |
| โครงสร้าง | อะคริลิก 3 มม. (ตัดเลเซอร์ / ก็อปปี้ตัดพลาสวูด 3 มม. ได้) |
| ของเหวี่ยง | พิมพ์ 3D (ตามกติกา สพฐ. อนุญาตเฉพาะชิ้นส่วนเหวี่ยง) |
| มอเตอร์ | เกียร์ 2 ตัว (ขับเคลื่อน) + 1 ตัว (เก็บลูกปิงปอง) |
| แบตเตอรี่ | AA 4–6 ก้อน |
| รีโมท | มีสาย ยาว ~2 ม. |

## ลำดับประกอบ (สรุป)

1. ตัดแผ่น A1–A12 จากอะคริลิก 3 มม.
2. พิมพ์ 3D ชิ้น P1–P5 (ข้อเหวี่ยง + คันโยกขา + ฝาครอบมอเตอร์)
3. ยึดมอเตอร์เกียร์ซ้าย/ขวา (M1, M2) บนแผ่น A3/A4
4. ประกอบขา 6 ขา (คู่หน้า–กลาง–หลัง) + ยางซิลิโคนที่ขากลาง
5. ติดแผ่นฐาน A1 + ขอบ A5/A6 + ถาดแบต A7
6. ติดชุดเหวี่ยงเก็บลูก (มอเตอร์ M3 + แขน P1 + กระบะ A11)
7. ใส่แบต + รีโมท + ทดสอบเดินและเก็บลูก

## กติกาแข่งขัน (อ้างอิง)

- ยาว ≤ 30 ซม. · กว้าง ≤ 20 ซม. · สูง ≤ 24 ซม. · น้ำหนักรวม ≤ 1.5 กก.
- มอเตอร์ ≤ 3 ตัว · แต่ละตัว ≤ 6V · แบต AA ≤ 6 ก้อน
- ภารกิจ: เก็บลูกขาวเข้าคอก · ไล่ลูกส้มออกจากคอก
